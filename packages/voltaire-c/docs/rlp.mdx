---
title: RLP Encoding
description: Recursive Length Prefix (RLP) encoding for byte strings and big-endian unsigned integers, plus hex conversion.
---

RLP (Recursive Length Prefix) is Ethereum's canonical binary serialization format for transactions, blocks, and state trie nodes. Every RLP function in `voltaire.h` writes into a caller-supplied buffer and returns the number of bytes written (`>= 0`) or a negative error code.

## Functions

### `primitives_rlp_encode_bytes`

```c
int primitives_rlp_encode_bytes(
    const unsigned char* data,
    size_t data_len,
    unsigned char* out_buf,
    size_t buf_len
);
```

Encodes `data[0..data_len]` as an RLP byte string. Native builds use a 4 KiB internal stack buffer; WASM builds use 2 MiB.

- **Returns:** Encoded byte count (`>= 0`), `PRIMITIVES_ERROR_OUT_OF_MEMORY` (`-4`) if input exceeds internal scratch capacity, or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`) if `buf_len` is too small.

### `primitives_rlp_encode_uint`

```c
int primitives_rlp_encode_uint(
    const unsigned char value_bytes[32],
    unsigned char* out_buf,
    size_t buf_len
);
```

Strips leading zero bytes from a 32-byte big-endian unsigned integer and RLP-encodes the minimal byte sequence. Zero encodes as the single byte `0x80` (empty byte string).

- **Returns:** Encoded byte count (`>= 0`), `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`), or `PRIMITIVES_ERROR_OUT_OF_MEMORY` (`-4`).

### `primitives_rlp_to_hex`

```c
int primitives_rlp_to_hex(
    const unsigned char* rlp_data,
    size_t rlp_len,
    unsigned char* out_buf,
    size_t buf_len
);
```

Formats `rlp_data[0..rlp_len]` as a `"0x"`-prefixed lowercase hex string. **Does not write a NUL terminator.** Uses an 8 KiB internal scratch buffer.

- **Returns:** Characters written (`>= 0`), `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`), or `PRIMITIVES_ERROR_OUT_OF_MEMORY` (`-4`).

### `primitives_rlp_from_hex`

```c
int primitives_rlp_from_hex(
    const char* hex,
    unsigned char* out_buf,
    size_t buf_len
);
```

Decodes a NUL-terminated hex string into raw RLP bytes in `out_buf`. Uses an 8 KiB internal scratch buffer.

- **Returns:** Bytes written (`>= 0`), `PRIMITIVES_ERROR_INVALID_HEX` (`-1`), or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`).

## RLP Wire Rules

| Input | Prefix byte | Layout |
|-------|-------------|--------|
| Single byte `0x00`..`0x7f` | None | `[byte]` |
| Byte string `0`..`55` bytes | `0x80 + len` | `[0x80 + len, data...]` (`0x80` for empty/zero) |
| Byte string `>= 56` bytes | `0xb7 + len_of_len` | `[0xb7 + k, be_len(k bytes), data...]` |
| List payload `0`..`55` bytes | `0xc0 + payload_len` | `[0xc0 + len, items...]` |
| List payload `>= 56` bytes | `0xf7 + len_of_len` | `[0xf7 + k, be_len(k bytes), items...]` |

## Example

```c
#include "voltaire.h"

#include <stdio.h>

int main(void) {
    /* Encode "dog" -> {0x83, 'd', 'o', 'g'} */
    static const unsigned char dog[] = {'d', 'o', 'g'};
    unsigned char encoded[16];
    int len = primitives_rlp_encode_bytes(dog, sizeof(dog), encoded, sizeof(encoded));
    if (len < 0) return 1;

    /* Encode 66 (0x42) as minimal big-endian uint -> {0x42} */
    unsigned char u256_be[32] = {0};
    u256_be[31] = 0x42;
    unsigned char uint_rlp[16];
    int uint_len = primitives_rlp_encode_uint(u256_be, uint_rlp, sizeof(uint_rlp));
    if (uint_len < 0) return 1;

    /* Format encoded bytes as hex (print using returned length, no NUL added) */
    unsigned char hex[64];
    int hex_len = primitives_rlp_to_hex(encoded, (size_t)len, hex, sizeof(hex));
    if (hex_len < 0) return 1;

    printf("RLP(\"dog\") = %.*s (%d bytes)\n", hex_len, (const char*)hex, len);
    printf("RLP(66)    = 0x%02x (%d byte)\n", uint_rlp[0], uint_len);

    return 0;
}
```
