---
title: Access List
description: EIP-2930 access list structs and intrinsic gas cost calculation.
---

An EIP-2930 access list pre-warms contract addresses and storage slots prior to EVM execution. `voltaire.h` defines `PrimitivesAccessListEntry` and computes the intrinsic gas surcharge for an entry array.

## Type and Constants

```c
#define ACCESS_LIST_ADDRESS_COST     2400
#define ACCESS_LIST_STORAGE_KEY_COST 1900

typedef struct {
    PrimitivesAddress address;
    const PrimitivesHash* storage_keys_ptr;
    size_t storage_keys_len;
} PrimitivesAccessListEntry;
```

## Function

### `primitives_access_list_gas_cost`

```c
int primitives_access_list_gas_cost(
    const PrimitivesAccessListEntry* entries,
    size_t entries_len,
    uint64_t* out_cost
);
```

Sums `2400` gas per entry plus `1900` gas per storage key across `entries[0..entries_len]` and writes the total to `*out_cost`. Returns `PRIMITIVES_SUCCESS` (`0`).

## Example

```c
#include "voltaire.h"

#include <inttypes.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    PrimitivesHash keys[2];
    memset(keys[0].bytes, 0x01, 32);
    memset(keys[1].bytes, 0x02, 32);

    PrimitivesAccessListEntry entry;
    if (primitives_address_from_hex(
            "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
            &entry.address) != PRIMITIVES_SUCCESS) {
        return 1;
    }
    entry.storage_keys_ptr = keys;
    entry.storage_keys_len = 2;

    uint64_t gas = 0;
    primitives_access_list_gas_cost(&entry, 1, &gas);
    printf("Access list gas: %" PRIu64 "\n", gas); /* 2400 + 2 * 1900 = 6200 */

    return 0;
}
```
