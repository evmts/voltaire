---
title: Event Logs
description: Ethereum event log address and indexed topic filter matching.
---

Event log filter functions test an emitted EVM log's 20-byte contract address and 32-byte indexed topics against `eth_getLogs`-style filter criteria. Every function returns `1` on match and `0` on mismatch.

## Functions

### `primitives_eventlog_matches_address`

```c
int primitives_eventlog_matches_address(
    const unsigned char log_address[20],
    const unsigned char (*filter_addresses)[20],
    size_t filter_count
);
```

Returns `1` if `filter_count == 0` (wildcard filter) or if `log_address` matches any entry in `filter_addresses[0..filter_count]`; otherwise returns `0`.

### `primitives_eventlog_matches_topic`

```c
int primitives_eventlog_matches_topic(
    const unsigned char log_topic[32],
    const unsigned char filter_topic[32],
    int null_topic
);
```

Returns `1` if `null_topic != 0` (wildcard) or if `log_topic` equals `filter_topic` byte-for-byte; otherwise `0`.

### `primitives_eventlog_matches_topics`

```c
int primitives_eventlog_matches_topics(
    const unsigned char (*log_topics)[32],
    size_t log_topic_count,
    const unsigned char (*filter_topics)[32],
    const int* filter_nulls,
    size_t filter_count
);
```

Evaluates positional topic filters `0..filter_count-1`. For each index `i`:
- If `filter_nulls[i] != 0`, position `i` matches any topic (even if `i >= log_topic_count`).
- Otherwise, requires `i < log_topic_count` and `memcmp(log_topics[i], filter_topics[i], 32) == 0`.

Returns `1` if every filter position matches, `0` otherwise.

## Example

```c
#include "voltaire.h"

#include <stdio.h>
#include <string.h>

int main(void) {
    PrimitivesAddress token;
    if (primitives_address_from_hex(
            "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48", &token) != PRIMITIVES_SUCCESS) {
        return 1;
    }

    /* Compute ERC-20 Transfer(address,address,uint256) topic0 (33 bytes, excluding NUL) */
    static const unsigned char sig[] = "Transfer(address,address,uint256)";
    PrimitivesHash transfer_topic;
    primitives_keccak256(sig, sizeof(sig) - 1, &transfer_topic);

    /* Sample log: topic0 = Transfer, topic1 = from, topic2 = to */
    unsigned char log_topics[3][32] = {0};
    memcpy(log_topics[0], transfer_topic.bytes, 32);
    memcpy(log_topics[2] + 12, token.bytes, 20);

    /* Address filter */
    unsigned char filter_addrs[1][20];
    memcpy(filter_addrs[0], token.bytes, 20);
    int addr_ok = primitives_eventlog_matches_address(token.bytes, filter_addrs, 1);

    /* Topic filter: [Transfer, null (any from), to == token] */
    unsigned char filter_topics[3][32] = {0};
    int filter_nulls[3] = {0, 1, 0};
    memcpy(filter_topics[0], transfer_topic.bytes, 32);
    memcpy(filter_topics[2] + 12, token.bytes, 20);

    int topics_ok = primitives_eventlog_matches_topics(
        log_topics, 3, filter_topics, filter_nulls, 3
    );

    printf("Address match: %d, Topics match: %d\n", addr_ok, topics_ok);
    return 0;
}
```
