---
title: Blob Operations
description: EIP-4844 blob encoding/decoding, size validation, and blob gas price and excess gas math.
---

Blob functions pack arbitrary payloads into fixed 128 KiB (`131072`-byte) EIP-4844 blobs and compute EIP-4844 blob fee market parameters.

## Constants and Blob Layout

```c
#define BYTES_PER_BLOB    131072 /* 4096 field elements * 32 bytes */
#define BLOB_GAS_PER_BLOB 131072 /* 2^17 blob gas per blob */
```

`primitives_blob_from_data` writes an 8-byte little-endian `uint64_t` length prefix at offset `0`, copies the payload to offsets `[8, 8 + data_len)`, and zero-pads the remainder to `131072` bytes. Maximum payload per blob is `BYTES_PER_BLOB - 8` (`131064` bytes).

| Offset | Size | Field |
|--------|------|-------|
| `0` | `8` | Little-endian `uint64_t` payload length |
| `8` | `data_len` | Raw payload bytes (`<= 131064`) |
| `8 + data_len` | `131064 - data_len` | Zero padding (`0x00`) |

## Functions

```c
int primitives_blob_from_data(
    const unsigned char* data,
    size_t data_len,
    unsigned char out_blob[131072]
);

int primitives_blob_to_data(
    const unsigned char blob[131072],
    unsigned char* out_data, /* must hold at least the encoded payload length */
    size_t* out_len
);

int      primitives_blob_is_valid(size_t blob_len);
uint64_t primitives_blob_calculate_gas(uint32_t blob_count);
uint32_t primitives_blob_estimate_count(size_t data_size);
uint64_t primitives_blob_calculate_gas_price(uint64_t excess_blob_gas);
uint64_t primitives_blob_calculate_excess_gas(uint64_t parent_excess, uint64_t parent_used);
```

- `primitives_blob_from_data` returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`) if `data_len > 131064`.
- `primitives_blob_to_data` reads the 8-byte length prefix, copies `len` bytes into `out_data`, sets `*out_len = len`, and returns `PRIMITIVES_SUCCESS` or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`).
- `primitives_blob_is_valid` returns `1` if `blob_len == 131072`, else `0`.
- `primitives_blob_calculate_gas` returns `(uint64_t)blob_count * 131072`.
- `primitives_blob_estimate_count` returns `ceil(data_size / 131064)`.
- `primitives_blob_calculate_gas_price` evaluates the EIP-4844 `fake_exponential` base fee per blob gas.
- `primitives_blob_calculate_excess_gas` computes `max(0, parent_excess + parent_used - TARGET_BLOB_GAS_PER_BLOCK)`.

## Example

```c
#include "voltaire.h"

#include <inttypes.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void) {
    static const unsigned char payload[] = "Hello, rollup world!";
    size_t payload_len = sizeof(payload) - 1;

    unsigned char* blob = malloc(BYTES_PER_BLOB);
    unsigned char* decoded = malloc(BYTES_PER_BLOB);
    if (!blob || !decoded) return 1;

    if (primitives_blob_from_data(payload, payload_len, blob) != PRIMITIVES_SUCCESS) {
        free(blob);
        free(decoded);
        return 1;
    }

    size_t decoded_len = 0;
    if (primitives_blob_to_data(blob, decoded, &decoded_len) != PRIMITIVES_SUCCESS) {
        free(blob);
        free(decoded);
        return 1;
    }

    uint32_t count = primitives_blob_estimate_count(payload_len);
    uint64_t gas = primitives_blob_calculate_gas(count);
    printf("Decoded: %.*s\n", (int)decoded_len, (const char*)decoded);
    printf("Blobs: %u, Blob gas: %" PRIu64 "\n", count, gas);

    free(blob);
    free(decoded);
    return 0;
}
```
