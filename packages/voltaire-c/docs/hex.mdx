---
title: Hex & U256 Utilities
description: Hexadecimal byte encoding/decoding and big-endian 256-bit unsigned integer conversion.
---

Hex functions convert between raw byte arrays and `0x`-prefixed hexadecimal strings. `PrimitivesU256` stores an unsigned 256-bit integer in big-endian byte order.

## Type

```c
typedef struct {
    unsigned char bytes[32]; /* big-endian 256-bit unsigned integer */
} PrimitivesU256;
```

## Functions

### `primitives_hex_to_bytes`

```c
int primitives_hex_to_bytes(const char* hex, unsigned char* out_buf, size_t buf_len);
```

Decodes a NUL-terminated hex string (with or without `0x`) into `out_buf`. Uses an internal 4 KiB scratch buffer (supporting decoded outputs up to 4096 bytes).

- **Returns:** Number of bytes written (`>= 0`), `PRIMITIVES_ERROR_INVALID_HEX` (`-1`), or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`) if `buf_len` is smaller than the decoded byte length.

### `primitives_bytes_to_hex`

```c
int primitives_bytes_to_hex(
    const unsigned char* data,
    size_t data_len,
    unsigned char* out_buf,
    size_t buf_len
);
```

Formats `data[0..data_len]` as lowercase `"0x"` followed by `2 * data_len` hex characters, then writes a NUL byte at `out_buf[2 + 2 * data_len]`.

<Warning>
`primitives_bytes_to_hex` checks `buf_len >= 2 + 2 * data_len` and then writes `out_buf[2 + 2 * data_len] = '\0'`. Always pass a buffer of at least `2 + 2 * data_len + 1` bytes so the NUL terminator stays in bounds.
</Warning>

- **Returns:** Character count excluding the NUL terminator (`2 + 2 * data_len`), or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`).

### `primitives_u256_from_hex`

```c
int primitives_u256_from_hex(const char* hex, PrimitivesU256* out_u256);
```

Parses a NUL-terminated hex string into a big-endian 32-byte `PrimitivesU256`. Returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_INVALID_HEX` (`-1`).

### `primitives_u256_to_hex`

```c
int primitives_u256_to_hex(const PrimitivesU256* value, unsigned char* buf, size_t buf_len);
```

Formats `*value` as a zero-padded 66-byte lowercase hex string (`"0x"` + 64 hex digits). **Does not write a NUL terminator.** Requires `buf_len >= 66`. Returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_INVALID_LENGTH` (`-2`).

## Buffer Sizing Reference

| Function | Minimum `buf_len` | Writes NUL | Return value on success |
|----------|-------------------|------------|-------------------------|
| `primitives_hex_to_bytes` | `decoded_len` | No | `decoded_len` (`int`) |
| `primitives_bytes_to_hex` | `2 + data_len * 2 + 1` | Yes | `2 + data_len * 2` (`int`) |
| `primitives_u256_from_hex` | `sizeof(PrimitivesU256)` (32) | N/A | `PRIMITIVES_SUCCESS` (`0`) |
| `primitives_u256_to_hex` | `66` (`67` if terminating manually) | No | `PRIMITIVES_SUCCESS` (`0`) |

## Example

```c
#include "voltaire.h"

#include <stdio.h>

int main(void) {
    /* Bytes -> hex (allocate 2 + 3*2 + 1 = 9 bytes minimum) */
    static const unsigned char data[] = {0x12, 0x34, 0x56};
    char hex[10];
    int hex_len = primitives_bytes_to_hex(data, sizeof(data), (unsigned char*)hex, sizeof(hex));
    if (hex_len < 0) return 1;
    printf("Hex (%d chars): %s\n", hex_len, hex); /* 0x123456 */

    /* Hex -> bytes */
    unsigned char decoded[16];
    int byte_len = primitives_hex_to_bytes("0xdeadbeef", decoded, sizeof(decoded));
    if (byte_len < 0) return 1;
    printf("Decoded %d bytes (first=0x%02x)\n", byte_len, decoded[0]);

    /* U256 hex round-trip */
    PrimitivesU256 value;
    if (primitives_u256_from_hex("0x1", &value) != PRIMITIVES_SUCCESS) return 1;

    char u256_hex[67];
    if (primitives_u256_to_hex(&value, (unsigned char*)u256_hex, sizeof(u256_hex)) != PRIMITIVES_SUCCESS) {
        return 1;
    }
    u256_hex[66] = '\0';
    printf("U256: %s\n", u256_hex);

    return 0;
}
```
