---
title: Hash Algorithms
description: Keccak-256, EIP-191 personal message hashing, SHA-256, RIPEMD-160, Blake2b-512, and constant-time hash comparison.
---

A `PrimitivesHash` is a fixed 32-byte digest struct. `voltaire.h` exposes Keccak-256 (Ethereum's pre-NIST sponge with `0x01` padding, distinct from SHA3-256), SHA-256, RIPEMD-160, and Blake2b-512.

## Type

```c
typedef struct {
    unsigned char bytes[32];
} PrimitivesHash;
```

## Digest Sizes

| Function | Algorithm | Output | Return codes |
|----------|-----------|--------|--------------|
| `primitives_keccak256` | Keccak-256 | `PrimitivesHash*` (32 B) | `0` |
| `primitives_eip191_hash_message` | EIP-191 + Keccak-256 | `PrimitivesHash*` (32 B) | `0`, `-4` |
| `primitives_solidity_keccak256` | Keccak-256 (packed bytes) | `PrimitivesHash*` (32 B) | `0` |
| `primitives_sha256` | SHA-256 | `unsigned char[32]` | `0`, `-5` |
| `primitives_solidity_sha256` | SHA-256 (packed bytes) | `unsigned char[32]` | `0`, `-5` |
| `primitives_ripemd160` | RIPEMD-160 | `unsigned char[20]` | `0`, `-5` |
| `primitives_blake2b` | Blake2b-512 | `unsigned char[64]` | `0` |

## Hash Functions

### `primitives_keccak256`

```c
int primitives_keccak256(
    const unsigned char* data,
    size_t data_len,
    PrimitivesHash* out_hash
);
```

Computes Keccak-256 over `data[0..data_len]` and writes 32 bytes to `out_hash->bytes`.

### `primitives_eip191_hash_message`

```c
int primitives_eip191_hash_message(
    const unsigned char* message,
    size_t message_len,
    PrimitivesHash* out_hash
);
```

Computes `keccak256("\x19Ethereum Signed Message:\n" || decimal(message_len) || message)`. Allocates temporary staging memory internally via the page allocator to support messages over 1 MiB. Returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_OUT_OF_MEMORY` (`-4`).

### `primitives_solidity_keccak256`

```c
int primitives_solidity_keccak256(
    const unsigned char* packed_data,
    size_t data_len,
    PrimitivesHash* out_hash
);
```

Computes Keccak-256 over caller-packed bytes (matching Solidity `keccak256(abi.encodePacked(...))`).

### `primitives_sha256` and `primitives_solidity_sha256`

```c
int primitives_sha256(
    const unsigned char* data,
    size_t data_len,
    unsigned char out_hash[32]
);

int primitives_solidity_sha256(
    const unsigned char* packed_data,
    size_t data_len,
    unsigned char out_hash[32]
);
```

Compute standard FIPS 180-4 SHA-256 into `out_hash[32]`.

### `primitives_ripemd160`

```c
int primitives_ripemd160(
    const unsigned char* data,
    size_t data_len,
    unsigned char out_hash[20]
);
```

Computes the 20-byte RIPEMD-160 digest (Ethereum precompile `0x03`).

### `primitives_blake2b`

```c
int primitives_blake2b(
    const unsigned char* data,
    size_t data_len,
    unsigned char out_hash[64]
);
```

Computes the unkeyed 64-byte Blake2b-512 digest.

## Hash Formatting and Comparison

### `primitives_hash_to_hex`

```c
int primitives_hash_to_hex(const PrimitivesHash* hash, unsigned char* buf);
```

Writes 66 lowercase ASCII bytes (`"0x"` + 64 hex chars) to `buf`. **Does not write a NUL terminator.** `buf` must hold at least 66 bytes.

### `primitives_hash_from_hex`

```c
int primitives_hash_from_hex(const char* hex, PrimitivesHash* out_hash);
```

Parses a 64-hex-digit string (optional `0x` prefix) into `*out_hash`. Returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_INVALID_HEX` (`-1`).

### `primitives_hash_equals`

```c
bool primitives_hash_equals(const PrimitivesHash* a, const PrimitivesHash* b);
```

Compares two 32-byte hashes in constant time.

## Example

```c
#include "voltaire.h"

#include <stdio.h>
#include <string.h>

int main(void) {
    static const unsigned char msg[] = "Hello, Ethereum!";
    size_t msg_len = sizeof(msg) - 1;

    PrimitivesHash keccak, eip191;
    primitives_keccak256(msg, msg_len, &keccak);
    primitives_eip191_hash_message(msg, msg_len, &eip191);

    unsigned char sha[32], ripemd[20], blake[64];
    primitives_sha256(msg, msg_len, sha);
    primitives_ripemd160(msg, msg_len, ripemd);
    primitives_blake2b(msg, msg_len, blake);

    unsigned char hex[66];
    primitives_hash_to_hex(&keccak, hex);
    printf("Keccak256: %.66s\n", (const char*)hex);

    primitives_hash_to_hex(&eip191, hex);
    printf("EIP-191:   %.66s\n", (const char*)hex);

    return 0;
}
```
