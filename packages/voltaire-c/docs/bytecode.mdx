---
title: Bytecode Analysis
description: EVM bytecode JUMPDEST analysis, PUSH-immediate boundary detection, validation, instruction scanning, and fusion pattern detection.
---

Bytecode functions parse raw EVM opcodes while skipping immediate payloads of `PUSH1` (`0x60`) through `PUSH32` (`0x7f`) so `0x5b` bytes inside push data are never mistaken for `JUMPDEST` instructions.

## Functions

### `primitives_bytecode_validate`

```c
int primitives_bytecode_validate(const unsigned char* code, size_t code_len);
```

Verifies that every `PUSH1`–`PUSH32` instruction has all of its immediate bytes present before `code_len`. Returns `PRIMITIVES_SUCCESS` (`0`) or `PRIMITIVES_ERROR_INVALID_INPUT` (`-5`) if a `PUSH` immediate is truncated.

### `primitives_bytecode_analyze_jumpdests`

```c
int primitives_bytecode_analyze_jumpdests(
    const unsigned char* code,
    size_t code_len,
    uint32_t* out_jumpdests,
    size_t max_jumpdests
);
```

Writes up to `max_jumpdests` byte offsets of valid `JUMPDEST` (`0x5b`) opcodes into `out_jumpdests`. Returns the number of offsets written.

### `primitives_bytecode_is_boundary` and `primitives_bytecode_is_valid_jumpdest`

```c
bool primitives_bytecode_is_boundary(const unsigned char* code, size_t code_len, uint32_t position);
bool primitives_bytecode_is_valid_jumpdest(const unsigned char* code, size_t code_len, uint32_t position);
```

`is_boundary` returns `true` when `position` lands on an opcode boundary rather than inside `PUSH` immediate data. `is_valid_jumpdest` returns `true` when `position` is a boundary and `code[position] == 0x5b`.

### `primitives_bytecode_get_next_pc`

```c
int64_t primitives_bytecode_get_next_pc(
    const unsigned char* code,
    size_t code_len,
    uint32_t current_pc
);
```

Returns the byte offset of the instruction following `current_pc` (`current_pc + 1 + push_size`), or `-1` if `current_pc >= code_len` or the instruction overflows `code_len`.

### `primitives_bytecode_scan`

```c
int primitives_bytecode_scan(
    const unsigned char* code,
    size_t code_len,
    uint32_t start_pc,
    uint32_t end_pc,
    unsigned char* out_instructions,
    size_t* out_len /* IN: capacity in bytes; OUT: bytes written */
);
```

Scans `[start_pc, end_pc)` and writes packed 8-byte instruction records into `out_instructions`. Sets `*out_len` to `count * 8` and returns `count`.

| Offset | Size | Field | Meaning |
|--------|------|-------|---------|
| `0` | `4` | `pc` (`uint32_t`, LE) | Instruction byte offset |
| `4` | `1` | `opcode` (`uint8_t`) | Opcode byte |
| `5` | `1` | `push_size` (`uint8_t`) | Immediate length (`1`–`32` for `PUSH`, else `0`) |
| `6` | `2` | `_padding` (`uint16_t`) | Zero padding |

### `primitives_bytecode_detect_fusions`

```c
int primitives_bytecode_detect_fusions(
    const unsigned char* code,
    size_t code_len,
    unsigned char* out_fusions,
    size_t* out_len /* IN: capacity in bytes; OUT: bytes written */
);
```

Detects `PUSH`+op (type `1`) and `DUP`+op (type `2`) pairs where the second opcode is arithmetic (`0x01`–`0x0c`) or comparison/bitwise (`0x10`–`0x1a`). Writes packed 7-byte records (`uint32_t pc`, `uint8_t pattern_type`, `uint8_t first_opcode`, `uint8_t second_opcode`), sets `*out_len` to `count * 7`, and returns `count`.

## Example

```c
#include "voltaire.h"

#include <stdio.h>

int main(void) {
    /* PUSH1 0x5b (not a jumpdest!), JUMPDEST (offset 2), ADD, STOP */
    static const unsigned char code[] = {0x60, 0x5b, 0x5b, 0x01, 0x00};

    if (primitives_bytecode_validate(code, sizeof(code)) != PRIMITIVES_SUCCESS) {
        return 1;
    }

    uint32_t jumpdests[8];
    int count = primitives_bytecode_analyze_jumpdests(code, sizeof(code), jumpdests, 8);
    printf("Valid JUMPDEST count: %d (first at pc=%u)\n", count, jumpdests[0]); /* 1, pc=2 */

    printf("pc=1 boundary? %d\n", primitives_bytecode_is_boundary(code, sizeof(code), 1)); /* 0 */
    printf("pc=2 jumpdest? %d\n", primitives_bytecode_is_valid_jumpdest(code, sizeof(code), 2)); /* 1 */

    unsigned char scan_buf[64];
    size_t scan_len = sizeof(scan_buf);
    int n_inst = primitives_bytecode_scan(code, sizeof(code), 0, (uint32_t)sizeof(code), scan_buf, &scan_len);
    printf("Scanned %d instructions (%zu bytes)\n", n_inst, scan_len);

    return 0;
}
```
