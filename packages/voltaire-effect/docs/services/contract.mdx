---
title: Contract Factory
description: Type-safe read, write, simulate, and event queries inferred from const ABIs.
---

`Contract(address, abi)` is an Effect factory that returns a typed contract instance bound to a single address. It is not a `Context.Tag` service; its methods require `ProviderService` for reads/simulations/events and `SignerService` for state-changing writes.

<Tip>
When an application interacts with multiple contracts, define them once in [Contract Registry](/services/contract-registry) instead of constructing instances per call site.
</Tip>

## Quick Start

```typescript
import { Effect, Layer } from 'effect'
import { Contract, Provider, HttpTransport } from 'voltaire-effect'

const erc20Abi = [
  {
    type: 'function',
    name: 'balanceOf',
    stateMutability: 'view',
    inputs: [{ name: 'account', type: 'address' }],
    outputs: [{ name: 'balance', type: 'uint256' }]
  },
  {
    type: 'function',
    name: 'transfer',
    stateMutability: 'nonpayable',
    inputs: [
      { name: 'to', type: 'address' },
      { name: 'amount', type: 'uint256' }
    ],
    outputs: [{ name: 'success', type: 'bool' }]
  }
] as const

const ProviderLayer = Provider.pipe(
  Layer.provide(HttpTransport('https://eth.llamarpc.com'))
)

const program = Effect.gen(function* () {
  const dai = yield* Contract(daiAddress, erc20Abi)
  return yield* dai.read.balanceOf(userAddress)
}).pipe(Effect.provide(ProviderLayer))
```

## Instance Methods

| Namespace | RPC / Execution | Required Service | Error Tag |
| --- | --- | --- | --- |
| `contract.read.<fn>(...args)` | `eth_call` (`view` / `pure`) | `ProviderService` | `ContractCallError` |
| `contract.simulate.<fn>(...args)` | `eth_call` dry-run for writes | `ProviderService` | `ContractCallError` |
| `contract.write.<fn>(...args)` | Sign + broadcast transaction | `SignerService` | `ContractWriteError` |
| `contract.getEvents(name, filter?)` | `eth_getLogs` + ABI decode | `ProviderService` | `ContractEventError` |

Declare ABIs with `as const` so TypeScript infers exact method names, parameter tuples, and return types:

```typescript
contract.read.balanceOf(userAddress)      // Compiles -> Effect<bigint, ContractCallError, ProviderService>
contract.read.balanceOf(123n)             // Compile error: invalid arg type
contract.write.transfer(recipient, 1000n) // Compiles -> Effect<HashType, ContractWriteError, SignerService>
contract.write.balanceOf(userAddress)     // Compile error: balanceOf is view
```

## Querying Events & Per-Request Overrides

```typescript
import { Schedule } from 'effect'
import { withTimeout, withRetrySchedule, withoutCache } from 'voltaire-effect'

const transfers = yield* token.getEvents('Transfer', {
  fromBlock: 18_000_000n,
  toBlock: 'latest',
  args: { from: userAddress }
})

const freshBalance = yield* token.read.balanceOf(user).pipe(
  withTimeout('5 seconds'),
  withoutCache
)

const txHash = yield* token.write.transfer(recipient, 100n).pipe(
  withRetrySchedule(
    Schedule.exponential('500 millis').pipe(
      Schedule.jittered,
      Schedule.compose(Schedule.recurs(3))
    )
  )
)
```

## Full Read -> Simulate -> Write Workflow

```typescript
import { Effect, Layer } from 'effect'
import { Contract, Signer, Provider, HttpTransport } from 'voltaire-effect'
import { Secp256k1Live, KeccakLive } from 'voltaire-effect/crypto'
import { Hex } from '@tevm/voltaire'

const privateKey = Hex.fromHex('0xac0974bec...')
const BaseDeps = Layer.mergeAll(
  Secp256k1Live,
  KeccakLive,
  HttpTransport('https://eth.llamarpc.com')
)
const SignerLayer = Signer.fromPrivateKey(privateKey, Provider).pipe(
  Layer.provide(BaseDeps)
)

const program = Effect.gen(function* () {
  const token = yield* Contract(tokenAddress, erc20Abi)
  const balanceBefore = yield* token.read.balanceOf(recipient)

  const ok = yield* token.simulate.transfer(recipient, 100n)
  if (!ok) return yield* Effect.fail(new Error('Transfer simulation returned false'))

  const txHash = yield* token.write.transfer(recipient, 100n)
  return { txHash, balanceBefore }
}).pipe(
  Effect.catchTags({
    ContractCallError: (e) => Effect.fail(e),
    ContractWriteError: (e) => Effect.fail(e)
  }),
  Effect.provide(SignerLayer)
)
```
