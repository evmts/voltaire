## Quick Lookup

| Symptom / Error | Cause | Fix |
| --- | --- | --- |
| `Service not found: ProviderService` | Missing `Provider` or transport layer | Compose `Provider.pipe(Layer.provide(HttpTransport(url)))` and provide once |
| `Service not found: KeccakService` | Encoding `Address.Checksummed` without crypto layer | Provide `KeccakLive` or `CryptoLive` |
| Effect returns without running | Missing `yield*` inside `Effect.gen` | Prefix every Effect call with `yield*` |
| `yield*` rejected on `Promise` | Used `await` inside `Effect.gen` | Wrap with `Effect.promise` or `Effect.tryPromise` |
| `ParseError` on valid hex address | Missing `0x` prefix or wrong byte length | Prefix with `0x`; 40 hex chars for Address, 64 for Hash |
| `TransportError: 429 Too Many Requests` | Unbounded RPC concurrency | Cap `{ concurrency: 3 }` or add `DefaultRateLimiter` |
| `FFI not available` | Running `MnemonicAccount` in browser/WASM | Use Node.js/Bun with FFI, or `LocalAccount` / `JsonRpcAccount` |
| `SignerError: nonce too low` | Concurrent sends racing on `pending` nonce | Serialize sends or assign explicit `nonce` values |

## Missing Service Error

**Error:** `Service not found: ProviderService`

Inspect the program's third type parameter `R` (`Effect<A, E, ProviderService>`) to see every unsatisfied requirement, then compose and provide the layer graph once:

```typescript
import { Effect, Layer } from 'effect'
import { Provider, HttpTransport } from 'voltaire-effect'

const ProviderLayer = Provider.pipe(
  Layer.provide(HttpTransport('https://eth.llamarpc.com'))
)

await Effect.runPromise(program.pipe(Effect.provide(ProviderLayer)))
```

## Wrong Layer Composition Order

**Symptom:** Type errors when wiring `Signer.Live` or duplicate service instances at runtime.

Compose dependencies bottom-up into one layer instead of chaining `Effect.provide`:

```typescript
import { Layer } from 'effect'
import { Signer, Provider, LocalAccount, HttpTransport } from 'voltaire-effect'
import { Secp256k1Live, KeccakLive } from 'voltaire-effect/crypto'

const CryptoLayer = Layer.mergeAll(Secp256k1Live, KeccakLive)
const TransportLayer = HttpTransport(rpcUrl)
const ProviderLayer = Provider.pipe(Layer.provide(TransportLayer))
const DepsLayer = Layer.mergeAll(LocalAccount(privateKey), ProviderLayer, CryptoLayer)

const SignerLayer = Signer.Live.pipe(Layer.provide(DepsLayer))
```

## Forgot `yield*` or Mixed `await`

Effects are lazy values. Omitting `yield*` constructs an Effect and discards it. Using `await` inside `Effect.gen` bypasses typed error tracking and interruption.

```typescript
// Wrong: getBlockNumber() is never executed
Effect.gen(function* () {
  getBlockNumber()
})

// Right: yield* every Effect; wrap external Promises with Effect.tryPromise
Effect.gen(function* () {
  const block = yield* getBlockNumber()
  const external = yield* Effect.tryPromise(() => fetchExternalPrice())
  return { block, external }
})
```

## `ParseError` on Hex Inputs

Schemas validate exact wire format:

| Schema | Expected Input |
| --- | --- |
| `Address.Hex` | `0x` + 40 hex characters (20 bytes) |
| `Hash.Hex` | `0x` + 64 hex characters (32 bytes) |
| `Uint.Uint256Hex` | `0x` + 1 to 64 hex characters |

```typescript
// Fails: missing 0x prefix
S.decodeSync(Address.Hex)('742d35Cc6634C0532925a3b844Bc9e7595f251e3')

// Succeeds
S.decodeSync(Address.Hex)('0x742d35Cc6634C0532925a3b844Bc9e7595f251e3')
```

## `Address.Checksummed` Requires `KeccakService`

EIP-55 encoding hashes the address with Keccak-256 and therefore requires `KeccakLive`:

```typescript
import { Effect } from 'effect'
import * as S from 'effect/Schema'
import * as Address from 'voltaire-effect/primitives/Address'
import { KeccakLive } from 'voltaire-effect/crypto/Keccak256'

const checksummed = await Effect.runPromise(
  S.encode(Address.Checksummed)(addr).pipe(Effect.provide(KeccakLive))
)
```

## RPC Timeouts and 429 Rate Limits

Set a transport-level timeout and retry schedule, bound concurrency on batch queries, or add `DefaultRateLimiter`:

```typescript
import { Effect, Schedule, Duration } from 'effect'
import { HttpTransport, DefaultRateLimiter } from 'voltaire-effect'

const transport = HttpTransport({
  url: 'https://eth.llamarpc.com',
  timeout: '60 seconds'
})

// Bound concurrency
const results = Effect.all(operations, { concurrency: 3 })

// Or retry with exponential backoff + timeout
const resilient = program.pipe(
  Effect.retry(Schedule.exponential('100 millis').pipe(Schedule.recurs(5))),
  Effect.timeout(Duration.seconds(30))
)

// Or apply token-bucket rate limiting
const limited = program.pipe(
  Effect.scoped,
  Effect.provide(DefaultRateLimiter({ global: { limit: 10, interval: '1 seconds' } }))
)
```

## Transaction Errors: Underpriced, Nonce Too Low, or Reverted

- **Underpriced:** Raise `maxPriorityFeePerGas` and `maxFeePerGas` explicitly:
  ```typescript
  yield* signer.sendTransaction({
    to,
    value,
    maxPriorityFeePerGas: 2_000_000_000n,
    maxFeePerGas: 100_000_000_000n
  })
  ```
- **Nonce too low:** Sequential sends auto-fetch `pending` nonces. For parallel broadcasts, track and pass `nonce` explicitly via `getTransactionCount(address, 'pending')`.
- **Contract reverted (`ContractCallError`):** Simulate before broadcasting to surface revert reasons without spending gas:
  ```typescript
  const ok = yield* contract.simulate.transfer(to, amount)
  ```

## Inspecting Full Failure Causes

Use `Effect.runPromiseExit` with `Cause.pretty` to inspect typed errors, defects, and fiber stacks:

```typescript
import { Effect, Cause, Exit } from 'effect'

const exit = await Effect.runPromiseExit(program)
if (Exit.isFailure(exit)) {
  console.error(Cause.pretty(exit.cause))
}
```
