This page compares representation, error handling, dependency injection, and bundle trade-offs across `voltaire-effect`, `@tevm/voltaire`, `viem`, and `ethers`.

## Feature Matrix

| Dimension | `voltaire-effect` | Base Voltaire (`@tevm/voltaire`) | `viem` | `ethers` v6 |
| --- | --- | --- | --- | --- |
| Primitive representation | Branded `Uint8Array` via Effect Schema | Branded `Uint8Array` | Branded `` `0x${string}` `` | `string` / class instances |
| Error model | Typed `Effect<A, E, R>` tagged unions | Thrown exceptions | Thrown exceptions | Thrown exceptions |
| Dependency injection | `Context.Tag` + `Layer` | Explicit function parameters | Client objects | Provider/Signer class instances |
| Retries & timeouts | Explicit `Schedule` / `Duration` / FiberRef | Manual | Implicit transport defaults | Manual |
| Testing | Swap `TestTransport` / `CryptoTest` layers | Direct calls / mock functions | Mock transport or module mocks | Custom providers / mocks |
| Runtime overhead | Voltaire + Effect (~15 KB gzipped) | Minimal (tree-shaken) | ~50 KB | ~130 KB+ |

### 2. JSON-RPC Balance Query

<Tabs>
  <Tab title="voltaire-effect">
```typescript
import { Effect, Layer } from 'effect'
import { getBalance, Provider, HttpTransport } from 'voltaire-effect'

const MainLayer = Provider.pipe(Layer.provide(HttpTransport(url)))
const balance = await Effect.runPromise(
  getBalance(addr).pipe(Effect.provide(MainLayer))
)
```
  </Tab>
  <Tab title="viem">
```typescript
import { createPublicClient, http } from 'viem'

const client = createPublicClient({ transport: http(url) })
const balance = await client.getBalance({ address })
```
  </Tab>
  <Tab title="ethers">
```typescript
import { JsonRpcProvider } from 'ethers'

const provider = new JsonRpcProvider(url)
const balance = await provider.getBalance(address)
```
  </Tab>
</Tabs>

### 3. Error Recovery

<Tabs>
  <Tab title="voltaire-effect">

```typescript
import { Effect } from 'effect'
import * as S from 'effect/Schema'
import * as Address from 'voltaire-effect/primitives/Address'

const parsed = S.decode(Address.Hex)(input).pipe(
  Effect.catchTag('ParseError', (e) => {
    // e is narrowed to ParseError with structured issue tree
    return Effect.succeed(fallback)
  })

```

```typescript
try {
  const addr = getAddress(input)
```

## Selection Guide

| Scenario | Recommended Choice |
| --- | --- |
| Small CLI script or strict bundle budget | [Base Voltaire](https://voltaire.tevm.sh) |
| Long-running backend indexer, relayer, or signer | `voltaire-effect` |
| Existing Effect codebase | `voltaire-effect` |
| Multi-provider failover and deterministic offline unit tests | `voltaire-effect` |
| Existing Wagmi/viem frontend without Effect | `viem` (migrate incrementally via `Effect.tryPromise`) |
