---
title: Block Module
description: Standalone Effect utilities for fetching blocks, block receipts, and lightweight reorg-tracking headers.
---

`voltaire-effect/block` provides standalone Effect functions requiring `TransportService` for one-off block and receipt fetches. For continuous streaming with automatic reorg detection, use [`makeBlockStream`](/services/block-stream).

## Quick Start

```typescript
import { Effect } from 'effect'
import * as Block from 'voltaire-effect/block'
import { HttpTransport } from 'voltaire-effect'

const program = Effect.gen(function* () {
  const block = yield* Block.fetchBlock(18_000_000n, 'header')
  return block.hash
}).pipe(Effect.provide(HttpTransport('https://eth.llamarpc.com')))
```

## Functions

| Function | Signature | Return Type |
| --- | --- | --- |
| `fetchBlock` | `(blockNumber: bigint, include: BlockInclude, retryOptions?: RetryOptions)` | `Effect<StreamBlock<TInclude>, BlockError, TransportService>` |
| `fetchBlockByHash` | `(blockHash: string, include: BlockInclude, retryOptions?: RetryOptions)` | `Effect<StreamBlock<TInclude>, BlockError, TransportService>` |
| `fetchBlockReceipts` | `(block: { hash: string; transactions?: Transaction[] })` | `Effect<Receipt[], BlockError, TransportService>` |
| `toLightBlock` | `(fullBlock: StreamBlock<any>)` | `LightBlock` (pure, synchronous) |

### Include Levels (`BlockInclude`)

| Level | Data Fetched |
| --- | --- |
| `'header'` | Block header fields only |
| `'transactions'` | Header + full transaction objects |
| `'receipts'` | Header + transactions + all transaction receipts |

`fetchBlockReceipts` calls `eth_getBlockReceipts` and falls back to per-transaction `eth_getTransactionReceipt` when a node does not support the batch RPC.

```typescript
import * as Block from 'voltaire-effect/block'

const header = yield* Block.fetchBlock(18_000_000n, 'header')
const withTxs = yield* Block.fetchBlock(18_000_000n, 'transactions')
const withReceipts = yield* Block.fetchBlock(18_000_000n, 'receipts', {
  maxRetries: 5,
  initialDelay: 500,
  maxDelay: 10_000
})

const byHash = yield* Block.fetchBlockByHash('0x1234...', 'transactions')
const light = Block.toLightBlock(withTxs)
```

## Types & Errors

```typescript
type BlockInclude = 'header' | 'transactions' | 'receipts'

interface LightBlock {
  readonly number: bigint
  readonly hash: BlockHashType
  readonly parentHash: BlockHashType
  readonly timestamp: bigint
}

interface RetryOptions {
  readonly maxRetries?: number   // Default: 3
  readonly initialDelay?: number // Default: 1000 ms
  readonly maxDelay?: number     // Default: 30000 ms
}
```

Handle failures via `Effect.catchTag('BlockError', ...)` (wraps `BlockNotFoundError`, `BlockStreamAbortedError`, `BlockRangeTooLargeError`).

## `Block` Module vs `makeBlockStream`

| Capability | `voltaire-effect/block` | `makeBlockStream` |
| --- | --- | --- |
| One-off historical fetch | Direct | Overkill |
| Continuous live tailing | Manual loop | Built-in `watch()` |
| Range backfill with chunking | Manual loop | Built-in `backfill()` |
| Automatic reorg detection | None | Built-in `ReorgEvent` |
