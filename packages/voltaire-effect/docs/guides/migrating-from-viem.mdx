Migrate from `viem` to `voltaire-effect` incrementally: both libraries can run side by side while you convert read paths first, then writes and streams.

## Conceptual Mapping

| `viem` | `voltaire-effect` |
| --- | --- |
| `await fn()` | `yield* fn()` inside `Effect.gen` |
| `try { ... } catch (e)` (`e: unknown`) | `Effect.catchTag` / `Effect.catchTags` (typed `_tag` union) |
| `createPublicClient({ transport: http(url) })` | `Provider.pipe(Layer.provide(HttpTransport(url)))` |
| `createWalletClient({ account, transport })` | `Signer.fromPrivateKey(key, Provider)` / `Signer.Live` |
| `privateKeyToAccount(key)` | `LocalAccount(key)` |
| `getAddress(str)` -> `` `0x${string}` `` | `S.decodeSync(Address.Hex)(str)` -> `AddressType` (`Uint8Array`) |
| `parseEther('1')` | `1_000_000_000_000_000_000n` (or `Denomination.toWei`) |
| `client.watchEvent({ onLogs })` | `makeEventStream().watch(...)` (`Effect.Stream`) |

## Side-by-Side Translations

### Reading Block Number & Contract State

  <Tab title="viem">
```typescript
import { createPublicClient, http, parseAbi } from 'viem'

const client = createPublicClient({ transport: http(rpcUrl) })
const block = await client.getBlockNumber()
const balance = await client.readContract({
  address: '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48',
  abi: parseAbi(['function balanceOf(address) view returns (uint256)']),
  functionName: 'balanceOf',
  args: [userAddress]
})
```
  </Tab>
  <Tab title="voltaire-effect">
```typescript
import { Effect, Layer } from 'effect'
import { getBlockNumber, readContract, Provider, HttpTransport } from 'voltaire-effect'
import * as Abi from 'voltaire-effect/primitives/Abi'

const ProviderLayer = Provider.pipe(Layer.provide(HttpTransport(rpcUrl)))

const program = Effect.gen(function* () {
  const block = yield* getBlockNumber()
  const balance = yield* readContract({
    address: '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48',
    abi: Abi.parseAbi(['function balanceOf(address) view returns (uint256)']),
    functionName: 'balanceOf',
    args: [userAddress]
  })
  return { block, balance }
})

const result = await Effect.runPromise(program.pipe(Effect.provide(ProviderLayer)))
```

### Sending Transactions

<Tabs>
  <Tab title="viem">
```typescript
import { createWalletClient, http, parseEther } from 'viem'
import { privateKeyToAccount } from 'viem/accounts'

const client = createWalletClient({
  account: privateKeyToAccount('0x...'),
  transport: http(rpcUrl)
})

const hash = await client.sendTransaction({
  to: '0x70997970C51812dc3A010C7d01b50e0d17dc79C8',
  value: parseEther('1')
})
```
  </Tab>
  <Tab title="voltaire-effect">
```typescript
import { Effect, Layer } from 'effect'
import { SignerService, Signer, Provider, HttpTransport } from 'voltaire-effect'
import { Secp256k1Live, KeccakLive } from 'voltaire-effect/crypto'
import { Hex } from '@tevm/voltaire'

const BaseDeps = Layer.mergeAll(Secp256k1Live, KeccakLive, HttpTransport(rpcUrl))
const SignerLayer = Signer.fromPrivateKey(Hex.fromHex('0x...'), Provider).pipe(
  Layer.provide(BaseDeps)
)

const program = Effect.gen(function* () {
  const signer = yield* SignerService
  return yield* signer.sendTransaction({
    to: '0x70997970C51812dc3A010C7d01b50e0d17dc79C8',
    value: 1_000_000_000_000_000_000n
  })
})

const hash = await Effect.runPromise(program.pipe(Effect.provide(SignerLayer)))
```

## Incremental Migration Bridge (`Effect.tryPromise`)

Keep an existing `viem` client in place while moving callers to Effect pipelines. Wrap async `viem` calls in `Effect.tryPromise` and boundary decoding in `S.decode`:

```typescript
import { Effect } from 'effect'
import * as S from 'effect/Schema'
import { createPublicClient, http } from 'viem'
import * as Address from 'voltaire-effect/primitives/Address'
import * as A from '@tevm/voltaire/Address'

const client = createPublicClient({ transport: http(rpcUrl) })

export const getBalanceBridge = (addressInput: string) =>
  Effect.gen(function* () {
    const addr = yield* S.decode(Address.Hex)(addressInput)
    const balance = yield* Effect.tryPromise({
      try: () => client.getBalance({ address: A.toHex(addr) as `0x${string}` }),
      catch: (error) => new Error(`RPC failed: ${String(error)}`)
    })
    return { addr, balance }
  })
```

Once callers consume the Effect, delete the `tryPromise` wrapper, call `getBalance(addr)`, and provide `ProviderLayer` at the entry point.

## Common Migration Pitfalls

- **Addresses are `Uint8Array`, not strings:** Convert to hex explicitly with `Address.toHex(addr)` when passing to legacy libraries.
- **Effects are lazy:** Always `yield*` Effects inside `Effect.gen`; never mix `await` inside a generator.
- **Compose layers once:** Wire `Provider.pipe(Layer.provide(HttpTransport(url)))` rather than merging `Provider` and `HttpTransport` without satisfying `Provider`'s requirement.
