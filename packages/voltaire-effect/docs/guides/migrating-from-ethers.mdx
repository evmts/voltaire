---
title: Migrating from ethers.js
description: Translate ethers.js v6 providers, wallets, HD wallets, contracts, and event listeners to voltaire-effect.
---

`ethers.js` models providers, wallets, and contracts as mutable class instances that throw untyped exceptions. `voltaire-effect` replaces them with immutable data, `Context.Tag` services, `Layer` composition, and typed `Effect` / `Stream` values.

## Conceptual Mapping

| `ethers.js` v6 | `voltaire-effect` |
| --- | --- |
| `new JsonRpcProvider(url)` | `Provider.pipe(Layer.provide(HttpTransport(url)))` |
| `new Wallet(key, provider)` | `Signer.fromPrivateKey(key, Provider)` |
| `HDNodeWallet.fromMnemonic(...)` | `MnemonicAccount(phrase, { index })` (`voltaire-effect/native`) |
| `new Contract(addr, abi, provider)` | `Contract(addr, abi)` or `makeContractRegistry(...)` |
| `contract.on('Transfer', cb)` | `makeEventStream().watch(...)` + `Effect.fork` / `Fiber.interrupt` |
| `try / catch (error.code)` | `Effect.catchTag('SignerError' \| 'TransportError', ...)` |
| `parseEther('1.0')` / `formatEther(wei)` | `Denomination.toWei` / `Denomination.fromWei` (`@tevm/voltaire`) |

const provider = new JsonRpcProvider('https://eth.llamarpc.com')
const blockNumber = await provider.getBlockNumber()

  <Tab title="voltaire-effect">
```typescript
import { Effect, Layer } from 'effect'
import { getBlockNumber, Contract, Provider, HttpTransport } from 'voltaire-effect'

const abi = [
  {
    type: 'function',
    name: 'balanceOf',
    stateMutability: 'view',
    inputs: [{ name: 'account', type: 'address' }],
    outputs: [{ name: 'balance', type: 'uint256' }]
  }
] as const

const ProviderLayer = Provider.pipe(
  Layer.provide(HttpTransport('https://eth.llamarpc.com'))
)

const program = Effect.gen(function* () {
  const blockNumber = yield* getBlockNumber()
  const token = yield* Contract(tokenAddress, abi)
  const balance = yield* token.read.balanceOf(userAddress)
  return { blockNumber, balance }
})

const result = await Effect.runPromise(program.pipe(Effect.provide(ProviderLayer)))
```

</Tabs>

### Event Listeners -> Structured Concurrency Streams

Replace callback registration (`contract.on` + `removeAllListeners`) with a forked `Stream` interrupted deterministically:

```typescript
import { Effect, Stream, Fiber, Duration } from 'effect'
import { makeEventStream, HttpTransport } from 'voltaire-effect'

const transferEvent = {
  type: 'event',
  name: 'Transfer',
  inputs: [
    { name: 'from', type: 'address', indexed: true },
    { name: 'to', type: 'address', indexed: true },
    { name: 'value', type: 'uint256', indexed: false }
  ]
} as const

const program = Effect.gen(function* () {
  const eventStream = yield* makeEventStream()

  const fiber = yield* Effect.fork(
    Stream.runForEach(
      eventStream.watch({ address: tokenAddress, event: transferEvent }),
      ({ log }) =>
        Effect.log(`Transfer: ${log.args.from} -> ${log.args.to}: ${log.args.value}`)
    )
  )

  yield* Effect.sleep(Duration.seconds(60))
  yield* Fiber.interrupt(fiber)
}).pipe(Effect.provide(HttpTransport('https://eth.llamarpc.com')))
```

## Gradual Coexistence Bridge

Wrap existing `ethers` provider calls with `Effect.tryPromise` so new services can adopt Effect pipelines immediately without rewriting every call site at once:

```typescript
import { Effect } from 'effect'
import * as S from 'effect/Schema'
import { JsonRpcProvider } from 'ethers'
import * as Address from 'voltaire-effect/primitives/Address'
import * as A from '@tevm/voltaire/Address'

const ethersProvider = new JsonRpcProvider(rpcUrl)

export const getBalanceBridge = (addressInput: string) =>
  Effect.gen(function* () {
    const addr = yield* S.decode(Address.Hex)(addressInput)
    const balance = yield* Effect.tryPromise({
      try: () => ethersProvider.getBalance(A.toHex(addr)),
      catch: (error) => new Error(`ethers RPC failed: ${String(error)}`)
    })
    return { addr, balance }
  })
```

Swap `Effect.tryPromise` for `getBalance(addr)` and provide `ProviderLayer` once the module is ready.
