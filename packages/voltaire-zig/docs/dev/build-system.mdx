Voltaire uses Zig's build system as the primary build tool, with pnpm scripts for TypeScript-specific tasks.

## Quick Reference

```bash
# Essential commands
zig build                    # Default build (Zig modules + C libs + Rust crypto_wrappers)
zig build test               # All Zig tests
pnpm test:run                # All TS tests
pnpm typecheck               # Typecheck all packages
```

## Zig Build Commands

### Core Builds

```bash
# Default build - Zig modules, C libraries, Rust crypto_wrappers
zig build

# Specific optimizations
zig build -Doptimize=Debug          # Debug symbols, no optimization
zig build -Doptimize=ReleaseFast    # Maximum performance
zig build -Doptimize=ReleaseSmall   # Minimum size
zig build -Doptimize=ReleaseSafe    # Safety checks enabled
```

### Testing

```bash
# All Zig tests (primitives + crypto + precompiles); build.zig has no test filter
zig build test

# TypeScript tests
zig build test-ts                                              # Every workspace test:run (pnpm -r test:run)
pnpm --filter @tevm/voltaire test:run src/primitives/Address   # Filter by path
pnpm --filter @tevm/voltaire test:wasm                         # WASM tests only
```

### TypeScript Targets

```bash
# Native FFI library (.dylib/.so)
zig build build-ts-native -Dwith-c-api=true      # ReleaseFast optimization

# WASM builds
zig build build-ts-wasm        # ReleaseSmall (size-optimized)
zig build build-ts-wasm-fast   # ReleaseFast (perf-optimized)
zig build crypto-wasm          # Individual crypto modules (tree-shaking)
```

### Quality Checks

```bash
# Formatting (zig build format recurses forever; call the formatters directly)
zig fmt build.zig packages/voltaire-zig/src packages/voltaire-zig/lib packages/voltaire-zig/examples  # Zig (add --check to verify only)
pnpm --filter @tevm/voltaire format    # TS (format:check to verify only)

# Linting
zig build lint                 # Lint TS (auto-fix)
pnpm -r run lint:check         # Check linting (no changes)

# Typecheck
pnpm typecheck                 # All packages
```

### Benchmarks

```bash
# Zig benchmarks (zbench)
zig build bench -Dwith-benches=true

# Filter benchmarks
zig build bench -Dwith-benches=true -Dfilter=keccak

# TypeScript benchmarks (colocated mitata *.bench.ts files)
cd packages/voltaire-ts && bun run src/crypto/keccak256.bench.ts
```

### Examples

```bash
# Run specific examples
zig build example-keccak256
zig build example-address
zig build example-secp256k1
zig build example-abi
zig build example-rlp
zig build example-transaction
zig build example-eip712
zig build example-eip4844
zig build example-eip7702
```

### Utilities

```bash
# Clean build artifacts
zig build clean                # Keep node_modules
zig build clean-all            # Root pnpm clean (also removes package dist/ and types/)

# Dependencies
pnpm install                   # JS dependencies (Zig and Cargo deps are fetched by zig build)

# Code generation
zig build generate-header      # Generate C header from c_api.zig
```

## pnpm Scripts

### Building

```bash
pnpm build                                 # Every package (zig build + dist + types)
pnpm build:zig                             # Just zig build
pnpm --filter @tevm/zig build:wasm         # Both WASM modes + crypto modules, staged in packages/voltaire-zig/wasm
pnpm --filter @tevm/voltaire build:dist    # TS bundling (tsup)
pnpm --filter @tevm/voltaire build:types   # Type generation
```

### Testing

```bash
pnpm --filter @tevm/voltaire test           # Vitest watch mode
pnpm --filter @tevm/voltaire test:run       # Vitest single run
pnpm --filter @tevm/voltaire test:coverage  # With coverage report
pnpm --filter @tevm/voltaire test:wasm      # WASM tests
```

### Development

```bash
cd packages/voltaire-ts/docs && npx mint dev   # Mintlify dev server (localhost:3000)
```

### Quality

```bash
pnpm --filter @tevm/voltaire format    # biome format
pnpm lint                              # pnpm -r lint (biome check --write in @tevm/voltaire)
pnpm typecheck                         # pnpm -r typecheck
```

### Analysis

```bash
cd packages/voltaire-ts && bun run src/crypto/keccak256.bench.ts   # Run one TS benchmark file
bun run scripts/measure-bundle-sizes.ts                            # Bundle size analysis (from the repo root)
```

## Build Configuration

### build.zig.zon

Zig dependencies:

```zig
.dependencies = .{
    .zbench = .{ ... },      // Performance benchmarking
    .clap = .{ ... },        // CLI argument parsing
    .@"z-ens-normalize" = .{ ... },  // ENS normalization
    .@"libwally-core" = .{ .path = "lib/libwally-core" },

```

### Cargo.toml

Rust dependencies for crypto:

```toml
[dependencies]
ark-bn254 = "0.4"
ark-bls12-381 = "0.4"
ark-ec = "0.4"
ark-ff = "0.4"

[features]

```

## Troubleshooting

### Common Issues

**Build fails with missing C library:**
```bash
# Ensure submodules are initialized
git submodule update --init --recursive

# Rebuild (zig build compiles the C dependencies)
zig build
```

**WASM build fails:**
```bash
# Check WASI target support
zig targets | grep wasm32-wasi

# Build with explicit target
zig build build-ts-wasm -Dtarget=wasm32-wasi
```

**No Zig test filter:** `build.zig` has no test filter option, so `zig build -Dtest-filter=...` fails with "invalid option". Run `zig build test`, or filter TS tests by path with `pnpm --filter @tevm/voltaire test:run src/primitives/Address`.

### Debug Build

```bash
# Build with debug symbols
zig build -Doptimize=Debug

# Run with verbose output
zig build test 2>&1 | head -200
```

## CI Pipeline

`zig build ci` is broken (it calls root scripts that do not exist). `.github/workflows/ci.yml` runs:

1. `zig build` and `zig build test` per optimize mode
2. Zig examples and the `wasm32-wasi` build
3. `zig fmt --check build.zig packages/voltaire-zig/src packages/voltaire-zig/lib packages/voltaire-zig/examples`
4. `pnpm --filter @tevm/zig build:wasm`, then TypeScript typecheck, `pnpm -r run lint:check`, `pnpm -r run format:check`
5. TS build, `pnpm --filter @tevm/voltaire lint:package`, and `pnpm --filter @tevm/voltaire test:coverage`

```bash
# Run the TypeScript checks locally before pushing
pnpm --filter @tevm/voltaire typecheck && pnpm -r run lint:check && pnpm -r run format:check && pnpm --filter @tevm/voltaire test:run
```
