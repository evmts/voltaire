Voltaire declares `.minimum_zig_version = "0.15.1"` in `build.zig.zon`. Follow these steps to add Voltaire to a Zig project and verify your build.

## Prerequisites

| Requirement | Version / Role |
| :--- | :--- |
| Zig | `0.15.1` or newer (tested with `0.15.2`) |
| Rust (`cargo`) | Required by `build.zig` to compile `crypto_wrappers` (`bn254` arkworks + `keccak` FFI) |
| C toolchain | Required to compile vendored `blst` and `c-kzg-4844` static libraries |

## Installation

<Tabs>

```bash
zig fetch --save=voltaire https://github.com/evmts/voltaire/archive/refs/heads/main.tar.gz
```
  </Tab>
  <Tab title="build.zig.zon">
```zig
.{
    .name = .my_eth_app,
    .version = "0.1.0",
    .minimum_zig_version = "0.15.1",
    .dependencies = .{
        .voltaire = .{
            .url = "https://github.com/evmts/voltaire/archive/refs/heads/main.tar.gz",
            // Run `zig fetch` to compute the content hash
            .hash = "<computed-by-zig-fetch>",
        },
    },
    .paths = .{ "build.zig", "build.zig.zon", "src" },
}
```
  </Tab>
</Tabs>

## Configure `build.zig`

Attach only the Voltaire modules your executable or library imports:

```zig
const std = @import("std");

pub fn build(b: *std.Build) void {
    const target = b.standardTargetOptions(.{});
    const optimize = b.standardOptimizeOption(.{});

    const voltaire = b.dependency("voltaire", .{
        .target = target,
        .optimize = optimize,
    });

    const exe = b.addExecutable(.{
        .name = "my-eth-app",
        .root_module = b.createModule(.{
            .root_source_file = b.path("src/main.zig"),
            .target = target,
            .optimize = optimize,
        }),
    });

    exe.root_module.addImport("primitives", voltaire.module("primitives"));
    exe.root_module.addImport("crypto", voltaire.module("crypto"));
    exe.root_module.addImport("precompiles", voltaire.module("precompiles"));

    b.installArtifact(exe);

    const run_cmd = b.addRunArtifact(exe);
    const run_step = b.step("run", "Run the application");
    run_step.dependOn(&run_cmd.step);
}
```

## Verify Installation

Create `src/main.zig`:

```zig
const std = @import("std");
const primitives = @import("primitives");
const crypto = @import("crypto");

pub fn main() !void {
    const addr = try primitives.Address.fromHex("0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e");
    const checksum = primitives.Address.toChecksummed(addr);

    const hash = primitives.Hash.keccak256("hello");
    const hash_hex = crypto.Hash.toHex(hash);

    std.debug.print("Address: {s}\n", .{&checksum});
    std.debug.print("Hash:    {s}\n", .{&hash_hex});
}
```

Run it:

```bash
zig build run
```

Expected output:

```text
Address: 0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e
Hash:    0x1c8aff950685c2ed4bc3174f3472287b56d9517b9c948127319a09a7a36deac8
```

## Working Inside the Voltaire Repository

If you cloned `evmts/voltaire` directly, `build.zig` exposes test, example, WASM, and benchmark steps:

```bash
# Run all Zig unit tests (primitives, crypto, precompiles, state-manager, blockchain)
zig build test

# Run bundled Zig examples
zig build example-address
zig build example-keccak256
zig build example-hex
zig build example-rlp
zig build example-abi
zig build example-transaction
zig build example-secp256k1

# Build WASM reactor targets (wasm32-wasi, ReleaseSmall)
zig build build-ts-wasm

# Build C API static/shared libraries (requires libwally-core submodule)
zig build -Dwith-c-api=true
```
