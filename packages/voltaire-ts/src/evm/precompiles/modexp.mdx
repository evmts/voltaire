# ModExp

The precompile at address `0x05` computes `base ** exponent % modulus`.
The input starts with three unsigned, big-endian 32-byte lengths, followed by
base, exponent, and modulus bytes. Missing header or operand bytes are
right-padded with zero. Output has exactly the declared modulus length;
a zero modulus produces zero bytes of that length.

From Osaka, each declared operand is limited to 1,024 bytes by EIP-7823.
The bounds apply even when the output would be empty. Invalid lengths and
insufficient gas cause call failure and consume all forwarded gas.
Earlier forks retain their historical length and pricing behavior.

## TypeScript execution

```typescript
import { modexp } from '@tevm/voltaire/precompiles';
import * as Hardfork from '@tevm/voltaire/Hardfork';

const input = new Uint8Array(99);
input[31] = 1;
input[63] = 1;
input[95] = 1;
input.set([2, 3, 5], 96);
const result = modexp(input, 500n, Hardfork.OSAKA);
console.log(result.success, result.output, result.gasUsed);
// true, Uint8Array([3]), 500n
```

The optional third argument selects the hardfork; omitting it retains Berlin
pricing for compatibility. The general `execute(address, input, gasLimit,
hardfork)` dispatcher forwards its hardfork to ModExp.

## Gas schedules

Let `x = max(baseLength, modulusLength)` and `w = ceil(x / 8)`.
The exponent head is the first `min(exponentLength, 32)` right-padded bytes.
Its iteration contribution is `max(bitLength(head) - 1, 0)`. For exponents longer
than 32 bytes, add eight iterations per remaining byte before Osaka and sixteen
from Osaka. The final iteration count is at least one.

| Fork | Multiplication complexity | Gas |
| --- | --- | --- |
| Byzantium through Istanbul | EIP-198 piecewise complexity | `floor(complexity * iterations / 20)` |
| Berlin through Prague | `w * w` | `max(200, floor(complexity * iterations / 3))` |
| Osaka onward | `16` when `x <= 32`, otherwise `2 * w * w` | `max(500, complexity * iterations)` |

EIP-198 complexity is `x*x` through 64 bytes, `floor(x*x/4) + 96*x - 3072`
through 1,024 bytes, and `floor(x*x/16) + 480*x - 199680` above that.
An empty base and modulus cost 200 gas in Berlin/Prague; Osaka still charges
for a long declared exponent, even when all its bytes are zero.

## Zig execution

```zig
const std = @import("std");
const precompiles = @import("precompiles");

pub fn main() !void {
    const allocator = std.heap.page_allocator;
    const result = try precompiles.modexp.execute(allocator, &.{}, 500, .OSAKA);
    defer result.deinit(allocator);
    std.debug.assert(result.output.len == 0);
    std.debug.assert(result.gas_used == 500);
}
```

The Zig module exports `MIN_GAS` (200), `MIN_GAS_OSAKA` (500), and
`MAX_INPUT_LENGTH_OSAKA` (1,024). Callers own the result and must deinitialize it.

See [EIP-198](https://eips.ethereum.org/EIPS/eip-198),
[EIP-2565](https://eips.ethereum.org/EIPS/eip-2565),
[EIP-7823](https://eips.ethereum.org/EIPS/eip-7823), and
[EIP-7883](https://eips.ethereum.org/EIPS/eip-7883).
