---
title: ModExp
description: Modular exponentiation and fork-aware gas calculation
---

The ModExp module provides bigint and byte-array modular exponentiation.
The mathematical helpers are separate from the EVM precompile, which enforces
operand bounds and consumes gas. The custom Zig arithmetic implementation
remains unaudited.

## TypeScript

```typescript
import { ModExp } from '@tevm/voltaire/ModExp';
import * as Hardfork from '@tevm/voltaire/Hardfork';

console.log(ModExp.modexp(2n, 10n, 1000n)); // 24n
const head = (1n << 256n) - 1n;
console.log(ModExp.calculateGas(32n, 32n, 32n, head)); // 1360n (Berlin default)
console.log(ModExp.calculateGas(32n, 32n, 32n, head, Hardfork.BYZANTIUM)); // 13056n
console.log(ModExp.calculateGas(32n, 32n, 32n, head, Hardfork.OSAKA)); // 4080n
```

`calculateGas(baseLength, exponentLength, modulusLength, exponentHead, hardfork?)`
uses bigint byte lengths and returns bigint gas. The head is the first
`min(exponentLength, 32)` bytes, including required right-padding. The optional
branded hardfork defaults to Berlin. `GasConstants.Precompile.calculateModExpCost`
exposes the same calculation. Neither gas helper enforces operand limits;
use the [precompile](/evm/precompiles/modexp) to execute under protocol rules.

## Zig

```zig
const std = @import("std");
const ModExp = @import("crypto").ModExp;
const Hardfork = @import("primitives").Hardfork;

pub fn main() !void {
    const allocator = std.heap.page_allocator;
    const result = try ModExp.modexp(allocator, &.{2}, &.{10}, &.{ 3, 232 });
    defer allocator.free(result);
    std.debug.assert(std.mem.eql(u8, result, &.{ 0, 24 }));
    const gas = ModExp.calculateGas(1, 1, 2, &.{10}, Hardfork.OSAKA);
    std.debug.assert(gas == 500);
}
```

Zig `calculateGas` accepts full declared byte lengths, a right-padded exponent
head of at most 32 bytes, and the active hardfork. It implements EIP-198,
EIP-2565, and EIP-7883; gas values saturate at `maxInt(u64)`.
The precompile rejects operands longer than 1,024 bytes from Osaka and charges
at least 500 gas, while historical forks retain their original schedules.
