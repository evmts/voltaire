title: Wallet Integration (BIP-39 + BIP-32/44)
description: End-to-end key derivation pipeline from BIP-39 mnemonic through BIP-32/44 HD keys to Ethereum addresses and signatures.
---

An Ethereum hierarchical deterministic (HD) wallet chains four modules: `Bip39` for mnemonic and seed generation, `HDWallet` for BIP-32/44 key derivation, `Secp256k1` / `PublicKey` for curve operations, and `Address` for EIP-55 address encoding.

## Derivation Pipeline

```mermaid
flowchart LR
    E["Entropy\n128-256 bits"] -->|"Bip39.generateMnemonic"| M["Mnemonic\n12-24 words"]
    M -->|"Bip39.mnemonicToSeed\nPBKDF2-HMAC-SHA512 (2048)"| S["Seed\n64 bytes"]
    S -->|"HDWallet.fromSeed\nHMAC-SHA512"| R["Master ExtendedKey\nm"]
    R -->|"HDWallet.deriveEthereum\nm/44'/60'/acct'/0/idx"| K["Child ExtendedKey\n32 B priv / 33 B pub"]
    K -->|"PublicKey.decompress\n(or Secp256k1.derivePublicKey)"| P["Uncompressed PubKey\n64 bytes (x || y)"]
    P -->|"Address.fromPublicKey\nkeccak256(pub)[12..32]"| A["Ethereum Address\n20 bytes"]
```

## Imports

`HDWallet` is exported from `@tevm/voltaire/HDWallet` and `@tevm/voltaire/native`. It is not re-exported on the root `@tevm/voltaire` barrel. All `HDWallet` functions take an `ExtendedKey` as their first argument.

```typescript
import { Address, Bip39, Hash, PublicKey, Secp256k1 } from '@tevm/voltaire';
import { HDWallet } from '@tevm/voltaire/HDWallet';
```

## Step-by-Step Pipeline

### 1. Generate and Validate a Mnemonic

```typescript
const mnemonic = Bip39.generateMnemonic(256); // 24 words (default)
if (!Bip39.validateMnemonic(mnemonic)) {
  throw new Error('Invalid mnemonic checksum');
}
```

### 2. Derive the 64-Byte Seed

```typescript
const passphrase = ''; // Optional 25th word; empty string by default
const seed = await Bip39.mnemonicToSeed(mnemonic, passphrase);
// Uint8Array(64)
```

### 3. Derive Master and BIP-44 Ethereum Keys

```typescript
const root = HDWallet.fromSeed(seed);

// m/44'/60'/0'/0/0
const eth0 = HDWallet.deriveEthereum(root, 0, 0);
// m/44'/60'/0'/0/1
const eth1 = HDWallet.deriveEthereum(root, 0, 1);

const privateKey = HDWallet.getPrivateKey(eth0); // Uint8Array(32) | null
const compressedPub = HDWallet.getPublicKey(eth0); // Uint8Array(33) | null
```

### 4. Derive Ethereum Address (Signing and Watch-Only)

`HDWallet.getPublicKey` returns a 33-byte compressed secp256k1 key (`0x02`/`0x03` prefix + `x`). Decompressing it with `PublicKey.decompress` works for both full keys and watch-only `xpub` keys where `getPrivateKey` returns `null`.

```typescript
function deriveAddress(hdKey: ReturnType<typeof HDWallet.fromSeed>): string {
  const compressed = HDWallet.getPublicKey(hdKey);
  if (!compressed) {
    throw new Error('Extended key has no public key');
  }
  const uncompressed = PublicKey.decompress(compressed); // 64 bytes (x || y)
  const address = Address.fromPublicKey(uncompressed);
  return Address.toChecksummed(address);
}
```

## Multi-Account and Watch-Only Wallets

Exporting an account-level `xpub` at `m/44'/60'/account'` lets an online server derive receiving addresses (`0/index`) without holding private keys. Hardened derivation is impossible from an `xpub`.

```typescript
// Offline signer: export account 0 extended public key
const account0 = HDWallet.derivePath(root, "m/44'/60'/0'");
const accountXpub = HDWallet.toExtendedPublicKey(account0);

// Online server: derive receiving addresses without private keys
const watchAccount = HDWallet.fromPublicExtendedKey(accountXpub);
console.log(HDWallet.canDeriveHardened(watchAccount)); // false
console.log(HDWallet.getPrivateKey(watchAccount));     // null

const externalChain = HDWallet.deriveChild(watchAccount, 0);
const receiveAddr0 = deriveAddress(HDWallet.deriveChild(externalChain, 0));
const receiveAddr1 = deriveAddress(HDWallet.deriveChild(externalChain, 1));
```

## Signing with a Derived Key

```typescript
const key0 = HDWallet.deriveEthereum(root, 0, 0);
const priv0 = HDWallet.getPrivateKey(key0);
if (!priv0) throw new Error('Watch-only key cannot sign');

const digest = Hash.keccak256String('hello ethereum');
const sig = Secp256k1.sign(digest, priv0); // { r, s, v }

const recoveredPub = Secp256k1.recoverPublicKey(sig, digest);
const recoveredAddr = Address.toChecksummed(Address.fromPublicKey(recoveredPub));
console.log(recoveredAddr === deriveAddress(key0)); // true
```

## Standard Wallet Derivation Paths

| Wallet | Path Pattern | Notes |
|--------|--------------|-------|
| MetaMask / BIP-44 default | `m/44'/60'/0'/0/i` | Increments address index `i` |
| Ledger Live | `m/44'/60'/i'/0/0` | Increments hardened account `i'` |
| Legacy MEW / Ledger | `m/44'/60'/0'/i` | Omits change level |

## Test Vector

The standard 12-word test mnemonic resolves deterministically at `m/44'/60'/0'/0/0`:

```typescript
const mnemonic =
  'abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about';
const seed = await Bip39.mnemonicToSeed(mnemonic);
const root = HDWallet.fromSeed(seed);
const eth0 = HDWallet.deriveEthereum(root, 0, 0);

console.log(deriveAddress(eth0));
// 0x9858EfFD232B4033E47d90003D41EC34EcaEda94
```

<Warning>
Zero temporary key buffers (`seed.fill(0)`, `priv0.fill(0)`) when done. Never log mnemonics, seeds, `xprv` strings, or private keys, and never persist unencrypted seeds; wrap keys with [Keystore](/crypto/keystore) for at-rest storage.
</Warning>
