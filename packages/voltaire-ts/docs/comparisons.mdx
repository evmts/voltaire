Voltaire, Viem, and Ethers.js solve different layers of the Ethereum stack. Voltaire focuses on validated byte primitives, multi-runtime cryptography, and EVM execution; higher-level workflows live in copyable [Skills](/concepts/skills) or [voltaire-effect](https://github.com/evmts/voltaire/tree/main/packages/voltaire-effect).

## Architectural Comparison

| Dimension | Voltaire | Viem | Ethers.js v6 |
| --- | --- | --- | --- |
| **Internal representation** | Branded `Uint8Array` / `bigint` | `0x${string}` hex strings | Mixed strings and classes |
| **Type safety** | Distinct brands (`AddressType` ≠ `HashType` ≠ `BytecodeType`) | Shared `0x${string}` alias across hex values | String addresses (`string`) |
| **Validation** | Enforced at construction | Function-by-function | Function-by-function |
| **Crypto backends** | Pure TS, Zig WASM, Bun Native FFI | Pure JS (`@noble/*`) | Pure JS (`@noble/*`) |
| **EVM & bytecode** | Built-in frame, opcodes, precompiles, analysis | Not included | Not included |
| **Providers & contracts** | Low-level EIP-1193 + copyable Skills / `voltaire-effect` | Built-in `PublicClient` / `WalletClient` | Built-in `Provider` / `Signer` / `Contract` |
| **Multi-language** | TS, Zig, C, Rust, Go, Python, Swift | TypeScript only | TypeScript only |

## Address Operations

Because Voltaire stores addresses as 20-byte `Uint8Array` instances, casing differences disappear at the boundary.

<Tabs>
  <Tab title="Voltaire">
    ```typescript
    import { Address } from '@tevm/voltaire';

    // Validate and construct once at the boundary
    const a = Address('0x742d35cc6634c0532925a3b844bc9e7595f51e3e');
    const b = Address('0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e');

    Address.toChecksummed(a); // "0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e"
    a.equals(b);        // true (byte-level comparison)
    Address.isValid('0x742d35cc6634c0532925a3b844bc9e7595f51e3e'); // true
    ```
  </Tab>
  <Tab title="Viem">
    ```typescript
    import { getAddress, isAddress, isAddressEqual } from 'viem';

    const a = '0x742d35cc6634c0532925a3b844bc9e7595f51e3e';
    const b = '0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e';

    getAddress(a);          // "0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e"
    isAddressEqual(a, b);   // true
    isAddress(a);           // true
    ```
  </Tab>
  <Tab title="Ethers.js">
    ```typescript
    import { ethers } from 'ethers';

    const a = ethers.getAddress('0x742d35cc6634c0532925a3b844bc9e7595f51e3e');
    const b = ethers.getAddress('0x742d35Cc6634C0532925a3b844Bc9e7595f51e3e');

    a === b;                // true (after normalizing both)
    ethers.isAddress(a);    // true
    ```
  </Tab>
</Tabs>

## Keccak-256 Hashing & Selectors

<Tabs>
  <Tab title="Voltaire">
    ```typescript
    import { Hex } from '@tevm/voltaire/Hex';
    import { Keccak256 } from '@tevm/voltaire/Keccak256';

    const digest = Keccak256.hashString('hello world');
    Hex.fromBytes(digest);
    // "0x47173285a8d7341e5e972fc677286384f802f8ef42a5ec5f03bbfa254cb01fad"

    const selector = Keccak256.selector('transfer(address,uint256)');
    Hex.fromBytes(selector);
    // "0xa9059cbb"
    ```
  </Tab>
  <Tab title="Viem">
    ```typescript
    import { keccak256, toFunctionSelector, toHex } from 'viem';

    const digest = keccak256(toHex('hello world'));
    // "0x47173285a8d7341e5e972fc677286384f802f8ef42a5ec5f03bbfa254cb01fad"

    const selector = toFunctionSelector('transfer(address,uint256)');
    // "0xa9059cbb"
    ```
  </Tab>
  <Tab title="Ethers.js">
    ```typescript
    import { ethers } from 'ethers';

    const digest = ethers.keccak256(ethers.toUtf8Bytes('hello world'));
    // "0x47173285a8d7341e5e972fc677286384f802f8ef42a5ec5f03bbfa254cb01fad"

    const selector = ethers.id('transfer(address,uint256)').slice(0, 10);
    // "0xa9059cbb"
    ```
  </Tab>
</Tabs>

## ABI Encoding

## When to Pick What

- **Choose Voltaire** when you want strict branded types, raw `Uint8Array` performance, WASM/native crypto acceleration, local EVM/bytecode tooling, cross-language parity with Zig/Rust/Go/C/Python/Swift, or custom-fitted abstractions via Skills.
- **Choose `voltaire-effect`** when you want Voltaire primitives paired with typed-error Effect.ts services, retries, timeouts, contract registries, and reorg-aware streams.
- **Mix freely:** Voltaire primitives expose `.toHex()` and `Uint8Array` directly, so you can adopt Voltaire incrementally inside an existing Viem or Ethers codebase.
