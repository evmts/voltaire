Install `@tevm/voltaire` and instantiate a provider from `@tevm/voltaire/provider`. Pair it with request builders from `@tevm/voltaire/jsonrpc` or pass plain `{ method, params }` objects.

  </Tab>

## Choosing a Provider

<Tabs>
  <Tab title="HttpProvider">
```typescript
import { HttpProvider } from '@tevm/voltaire/provider';

const provider = new HttpProvider({
  url: 'https://eth.llamarpc.com',
  headers: { Authorization: 'Bearer token' },
  timeout: 30_000,   // default: 30000 ms
  retry: 3,          // default: 3 attempts on network errors
  retryDelay: 1000,  // default: 1000 ms
});

// Shorthand with defaults
const simple = new HttpProvider('https://eth.llamarpc.com');
```
  </Tab>
  <Tab title="WebSocketProvider">
```typescript
import { WebSocketProvider } from '@tevm/voltaire/provider';

const provider = new WebSocketProvider({
  url: 'wss://eth.llamarpc.com',
  reconnect: true,          // default: true
  reconnectDelay: 5000,     // default: 5000 ms
  maxReconnectAttempts: 0,  // default: 0 (unlimited)
});

await provider.connect();
```
  </Tab>

Browser wallets (`window.ethereum` or providers discovered via `EIP6963`) implement the same `request(args)` contract and work directly with Voltaire request builders.

## Making Requests

### Block Number

```typescript
import { Rpc } from '@tevm/voltaire/jsonrpc';
import { HttpProvider } from '@tevm/voltaire/provider';

const provider = new HttpProvider('https://eth.llamarpc.com');

const blockHex = (await provider.request(Rpc.Eth.BlockNumberRequest())) as string;
console.log('Current block:', BigInt(blockHex));
```

### Account Balance and Nonce

```typescript
import { Address } from '@tevm/voltaire/Address';
import { Rpc } from '@tevm/voltaire/jsonrpc';

const account = Address('0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb0');

const [balanceHex, nonceHex, code] = (await Promise.all([
  provider.request(Rpc.Eth.GetBalanceRequest(account, 'latest')),
  provider.request(Rpc.Eth.GetTransactionCountRequest(account, 'latest')),
  provider.request(Rpc.Eth.GetCodeRequest(account, 'latest')),
])) as [string, string, string];

console.log('Wei:', BigInt(balanceHex));
console.log('Nonce:', Number(BigInt(nonceHex)));
console.log('Is contract:', code !== '0x');
```

### Read-Only Contract Call (`eth_call`)

```typescript
import { Abi } from '@tevm/voltaire/Abi';
import { Hex } from '@tevm/voltaire/Hex';
import { Rpc } from '@tevm/voltaire/jsonrpc';

const usdc = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48' as const;
const erc20 = Abi([
  {
    type: 'function',
    name: 'totalSupply',
    stateMutability: 'view',
    inputs: [],
    outputs: [{ name: '', type: 'uint256' }],
  },
]);

const calldata = Hex.fromBytes(erc20.encode('totalSupply', []));
const raw = (await provider.request(
  Rpc.Eth.CallRequest({ to: usdc, data: calldata }, 'latest'),
)) as `0x${string}`;

const [supply] = erc20.decode('totalSupply', Hex.toBytes(raw));
console.log('USDC totalSupply:', supply);
```

### Historical State

Pass a hex-encoded block number instead of `'latest'` (requires an archive node for older blocks):

```typescript
const balanceAt1M = (await provider.request(
  Rpc.Eth.GetBalanceRequest('0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb0', '0xf4240'),
)) as string;
```

## Error Handling

`provider.request()` rejects with an `RpcError` (`{ code: number, message: string, data?: unknown }`) on JSON-RPC errors, HTTP non-2xx responses, or timeouts:

```typescript
try {
  await provider.request(Rpc.Eth.CallRequest({ to: usdc, data: '0xdeadbeef' }, 'latest'));
} catch (err) {
  const rpcErr = err as { code?: number; message?: string; data?: unknown };
  console.error('RPC failed:', rpcErr.code, rpcErr.message, rpcErr.data);
}
```

## Common Pitfalls

1. **Request builders do not perform I/O.** `Rpc.Eth.BlockNumberRequest()` returns `{ method: 'eth_blockNumber', params: [] }`. Pass that object to `provider.request(...)`.
2. **`HttpProvider` is stateless.** Registering `.on('connect', ...)` on `HttpProvider` never fires; use `WebSocketProvider` for connection lifecycle events and pub/sub streams.
3. **Node.js WebSockets.** `WebSocketProvider` uses `globalThis.WebSocket`. Node 22+ and Bun provide it natively; older Node versions require assigning a polyfill such as `ws` to `globalThis.WebSocket`.
