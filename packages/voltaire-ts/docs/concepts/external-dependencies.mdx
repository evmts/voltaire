---
title: External Dependencies
description: Audited cryptographic, normalization, and ABI dependencies included in Voltaire and why each was chosen.
---

Voltaire avoids "zero-dependency" dogma where audited, spec-authoritative libraries provide stronger security than hand-rolled code. Every dependency is chosen for audit pedigree, constant-time guarantees, or specification authority.

## TypeScript Dependencies (`@tevm/voltaire`)

| Package | Kind | Used By | Why |
| --- | --- | --- | --- |
| `@noble/ciphers` | Runtime | `AesGcm`, `ChaCha20Poly1305`, `Keystore` | Audited, constant-time AEAD and stream ciphers |
| `@scure/bip32` | Runtime | `HDWallet` | Audited BIP-32 hierarchical deterministic key derivation |
| `@scure/bip39` | Runtime | `Bip39` | Audited BIP-39 mnemonic generation and seed derivation |
| `@adraffy/ens-normalize` | Runtime | `Ens` | Authoritative ENSIP-15 Unicode normalization by the spec author |
| `@shazow/whatsabi` | Runtime | `Bytecode` | ABI inference from unverified EVM bytecode |
| `@tevm/chains` | Runtime | `Chain` | Up-to-date chain IDs, RPC endpoints, and explorer metadata |
| `abitype` | Peer | `Abi` | Compile-time TypeScript inference from Solidity ABI definitions |
| `effect` | Optional | `voltaire-effect` | Typed-error Effect.ts integration (never bundled unless imported) |

## Native & WASM Dependencies (Zig Build)

Native and WASM builds statically link battle-tested C and Rust cryptographic libraries:

| Library | Language | Used For |
| --- | --- | --- |
| `blst` | C / Assembly | BLS12-381 signatures and pairings (EIP-2537) |
| `c-kzg-4844` | C | EIP-4844 KZG commitments and proofs |
| `ark-bn254` / `ark-bls12-381` | Rust | Elliptic curve pairings and ZK precompiles |

All TypeScript subpath exports declare `"sideEffects": false`, so importing `@tevm/voltaire/Address` never pulls `@adraffy/ens-normalize`, `@scure/bip39`, or `@shazow/whatsabi` into your bundle.
