---
title: Schema Annotations
description: Attach titles, descriptions, examples, and custom error messages to Effect schemas for JSON Schema and UI forms.
---

When using Voltaire's Effect.ts schemas (`voltaire-effect`), schema annotations carry human-readable metadata alongside runtime validation. That metadata drives clearer parse errors, OpenAPI / JSON Schema generation, and UI form labels from a single source of truth.

## Standard Annotations

| Key | Purpose | Example |
| --- | --- | --- |
| `identifier` | Stable schema ID | `"Address.Hex"` |
| `title` | Display label for UI forms and OpenAPI | `"Ethereum Address"` |
| `description` | Concise field documentation | `"20-byte Ethereum address as 0x-prefixed hex"` |
| `examples` | Valid sample inputs for docs & placeholders | `["0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"]` |
| `message` | Custom validation error factory | `() => "Expected 40 hex chars with 0x prefix"` |

## Adding Annotations

```typescript
import * as S from 'effect/Schema';

const RecipientSchema = S.String.pipe(
  S.pattern(/^0x[a-fA-F0-9]{40}$/),
  S.annotations({
    identifier: 'RecipientAddress',
    title: 'Recipient Address',
    description: '20-byte Ethereum destination address (0x-prefixed hex)',
    examples: ['0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045'],
    message: () => 'Expected a valid 20-byte Ethereum address (0x followed by 40 hex characters)',
  }),
);
```

## Generating JSON Schema / OpenAPI

```typescript
import { JSONSchema } from 'effect';

const jsonSchema = JSONSchema.make(RecipientSchema);
// {
//   "$schema": "http://json-schema.org/draft-07/schema#",
//   "type": "string",
//   "title": "Recipient Address",
//   "description": "20-byte Ethereum destination address (0x-prefixed hex)",
//   "pattern": "^0x[a-fA-F0-9]{40}$",
//   "examples": ["0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"]
// }
```

See the [`voltaire-effect` documentation](https://github.com/evmts/voltaire/tree/main/packages/voltaire-effect) for built-in schemas covering `Address`, `Hash`, `Hex`, `Uint`, `Signature`, `Transaction`, and `Siwe`.
