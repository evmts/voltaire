`Hardfork` (`HardforkType`) represents an Ethereum protocol upgrade in chronological order from `FRONTIER` through `OSAKA` (`DEFAULT`) and `AMSTERDAM`, providing version comparisons, range queries, and EIP activation predicates.

```mermaid
flowchart LR
  F["FRONTIER"] --> B["BYZANTIUM"] --> I["ISTANBUL"] --> Be["BERLIN"] --> L["LONDON"] --> M["MERGE"] --> S["SHANGHAI"] --> C["CANCUN"] --> P["PRAGUE"] --> O["OSAKA (DEFAULT)"] --> A["AMSTERDAM"]
```

## Hardfork Constants

| Constant | String ID | Milestone EIPs |
| --- | --- | --- |
| `FRONTIER` | `"frontier"` | Initial EVM |
| `HOMESTEAD` | `"homestead"` | `DELEGATECALL`, EIP-2 low-`s` |
| `DAO` | `"dao"` | Irregular state transition |
| `TANGERINE_WHISTLE` | `"tangerinewhistle"` | EIP-150 63/64 gas rule |
| `SPURIOUS_DRAGON` | `"spuriousdragon"` | EIP-155 replay protection, EIP-161 empty accounts |
| `BYZANTIUM` | `"byzantium"` | `REVERT`, `STATICCALL`, `RETURNDATASIZE`, receipt `status` |
| `CONSTANTINOPLE` / `PETERSBURG` | `"constantinople"` / `"petersburg"` | `CREATE2`, `SHL`/`SHR`/`SAR`, `EXTCODEHASH` (`constantinoplefix` alias) |
| `ISTANBUL` | `"istanbul"` | EIP-2200 `SSTORE`, `CHAINID`, `SELFBALANCE` |
| `BERLIN` | `"berlin"` | EIP-2929 cold/warm gas, EIP-2930 access lists |
| `LONDON` | `"london"` | EIP-1559 base fee, EIP-3529 refund cap, `BASEFEE` |
| `MERGE` | `"merge"` (`paris` alias) | Proof-of-Stake, `PREVRANDAO` |
| `SHANGHAI` | `"shanghai"` | EIP-3855 `PUSH0`, EIP-3860 initcode limit, EIP-4895 withdrawals |
| `CANCUN` | `"cancun"` | EIP-4844 blobs, EIP-1153 `TLOAD`/`TSTORE`, EIP-5656 `MCOPY` |
| `PRAGUE` | `"prague"` | EIP-7702 EOA delegation, EIP-2537 BLS12-381 precompiles |
| `OSAKA` (`DEFAULT`) | `"osaka"` | [Fusaka](/primitives/hardfork/osaka): EIP-7951 `P256VERIFY`, EIP-7823/7883 ModExp bounds and repricing, EIP-7918 blob reserve price, EIP-7934 RLP block size cap, EIP-7594 PeerDAS, EIP-7892 BPO blob schedules |
| `AMSTERDAM` | `"amsterdam"` (`glamsterdam` alias) | Upcoming (Glamsterdam): EIP-7928 [block-level access lists](/primitives/block-access-list) |

Difficulty-bomb forks also included: `MUIR_GLACIER`, `ARROW_GLACIER`, `GRAY_GLACIER`.

`Hardfork.DEFAULT` is `OSAKA`, the latest activated mainnet fork. `AMSTERDAM` is defined for forward-looking feature checks but is not yet scheduled on mainnet.

## Quick Start

```typescript
import { Hardfork } from '@tevm/voltaire';

const fork = Hardfork.fromString('cancun'); // Hardfork.CANCUN
Hardfork.isAtLeast(Hardfork.PRAGUE, Hardfork.CANCUN); // true
Hardfork.supportsBlobs(Hardfork.CANCUN);              // true
Hardfork.supportsTransientStorage(Hardfork.SHANGHAI); // false
Hardfork.isPoS(Hardfork.MERGE);                       // true

Hardfork.range(Hardfork.BERLIN, Hardfork.SHANGHAI);
// [BERLIN, LONDON, ARROW_GLACIER, GRAY_GLACIER, MERGE, SHANGHAI]
```

Import from `@tevm/voltaire` or `@tevm/voltaire/Hardfork`.
