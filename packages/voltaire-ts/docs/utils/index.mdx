`@tevm/voltaire/utils` exports async control-flow primitives for RPC transport reliability: exponential backoff retries, token-bucket rate limiting, polling, deadlines, and request batching.

Source: [packages/voltaire-ts/src/utils/index.ts](https://github.com/evmts/voltaire/blob/main/packages/voltaire-ts/src/utils/index.ts).

```mermaid
flowchart LR
  Call["Application Call"] --> Batch["BatchQueue / AsyncQueue\n(coalesce & bound concurrency)"]
  Batch --> Rate["RateLimiter\n(token bucket)"]
  Rate --> Retry["retryWithBackoff\n(exponential + jitter)"]
  Retry --> TO["withTimeout\n(deadline + AbortSignal)"]
  TO --> RPC["provider.request(...)"]
```

## Exports

| Module | Exports | Primary Use |
| --- | --- | --- |
| [Retry](/utils/retry) | `retryWithBackoff`, `withRetry`, `RetryOptions` | Recover from transient RPC / network failures |
| [Rate Limit](/utils/rate-limit) | `RateLimiter`, `throttle`, `debounce`, `RateLimiterOptions` | Respect provider RPS/CU quotas and UI event bursts |
| [Polling](/utils/polling) | `poll`, `pollUntil`, `pollForReceipt`, `pollWithBackoff`, `PollOptions` | Wait for transaction receipts, block heights, or state changes |
| [Timeout](/utils/timeout) | `TimeoutError`, `withTimeout`, `wrapWithTimeout`, `executeWithTimeout`, `sleep`, `createDeferred`, `TimeoutOptions` | Enforce per-call deadlines and `AbortSignal` cancellation |
| [Batch](/utils/batch) | `BatchQueue`, `createBatchedFunction`, `AsyncQueue`, `BatchQueueOptions` | Coalesce concurrent requests and cap parallel fan-out |

## Composing Utilities

Combine utilities around an EIP-1193 `provider.request` call to build a resilient RPC pipeline:

```typescript
import { Rpc } from '@tevm/voltaire/jsonrpc';
import { HttpProvider } from '@tevm/voltaire/provider';
import { RateLimiter, retryWithBackoff, withTimeout } from '@tevm/voltaire/utils';

const provider = new HttpProvider('https://eth.llamarpc.com');
const limiter = new RateLimiter({ maxRequests: 20, interval: 1000, strategy: 'queue' });

async function safeRequest<T>(req: { method: string; params?: readonly unknown[] }): Promise<T> {
  return limiter.execute(() =>
    retryWithBackoff(
      () => withTimeout(provider.request(req) as Promise<T>, { ms: 5000 }),
      { maxRetries: 3, initialDelay: 500, jitter: true },
    ),
  );
}

const blockNumber = await safeRequest<string>(Rpc.Eth.BlockNumberRequest());
```
