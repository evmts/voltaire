---
title: Logging Instructions
description: EVM LOG0-LOG4 event emission opcode handlers (0xa0-0xa4) with static-call write protection.
---

`Log` (`@tevm/voltaire/evm`) implements the `5` event-logging opcodes (`0xa0`-`0xa4`). Each handler reads `size` bytes from `frame.memory` at `offset`, pops `0` to `4` 32-byte indexed topics, and appends `{ address: frame.address, topics, data }` to `frame.logs`. All `LOG*` opcodes return `{ type: "WriteProtection" }` when `frame.isStatic === true`.

## Opcode Table

| Opcode | Export | Gas | Stack (`top` first) |
|--------|--------|-----|---------------------|
| `0xa0` | [handler_0xa0_LOG0](/evm/instructions/log/log0) | `375 + 8 * size + mem` | `offset, size ->` |
| `0xa1` | [handler_0xa1_LOG1](/evm/instructions/log/log1) | `750 + 8 * size + mem` | `offset, size, topic0 ->` |
| `0xa2` | [handler_0xa2_LOG2](/evm/instructions/log/log2) | `1125 + 8 * size + mem` | `offset, size, topic0, topic1 ->` |
| `0xa3` | [handler_0xa3_LOG3](/evm/instructions/log/log3) | `1500 + 8 * size + mem` | `offset, size, topic0..2 ->` |
| `0xa4` | [handler_0xa4_LOG4](/evm/instructions/log/log4) | `1875 + 8 * size + mem` | `offset, size, topic0..3 ->` |

## Usage

```typescript
import { Frame, Log } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 10_000n });
Frame.pushStack(frame, 0xdeadbeefn); // topic0
Frame.pushStack(frame, 0n);          // size
Frame.pushStack(frame, 0n);          // offset (top)

const err = Log.handler_0xa1_LOG1(frame); // null
console.log(err, frame.logs?.length);     // null, 1
```
