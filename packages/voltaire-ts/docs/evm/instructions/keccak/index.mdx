title: Keccak Instruction (SHA3)

---

`Keccak` (`@tevm/voltaire/evm`) exports `sha3`, implementing opcode `0x20` (`KECCAK256` / `SHA3`). It reads `size` bytes from `frame.memory` starting at `offset`, computes their pre-NIST Keccak-256 digest, and pushes the 256-bit result onto the stack.

## Opcode Table

| Opcode | Handler | Gas | Stack (`top` first) | Description |
|--------|---------|-----|---------------------|-------------|
| `0x20` | [sha3](/evm/instructions/keccak/sha3) | `30 + 6 * ceil(size / 32) + memExpansion` | `offset, size -> hash` | Keccak-256 hash of `memory[offset..offset+size]` |

## Usage

```typescript
import { Frame, Keccak } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 10_000n });
Frame.pushStack(frame, 0n); // size = 0
Frame.pushStack(frame, 0n); // offset = 0 (top)

const err = Keccak.sha3(frame); // null
const digest = Frame.popStack(frame).value;
// 0xc5d2460186f7233c927e7db2dcc703c0e500b653ca82273b7bfad8045d85a470n
```
