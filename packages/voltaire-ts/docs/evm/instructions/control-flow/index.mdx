`Control` (`@tevm/voltaire/evm`) implements the `7` control-flow opcodes managing jumps, program counter inspection, and normal or reverting execution termination.

## Opcode Table

| Opcode | Export | Base Gas | Stack (`top` first) | Behavior |
|--------|--------|----------|---------------------|----------|
| `0x00` | [handler_0x00_STOP](/evm/instructions/control-flow/stop) | `0` | `->` | Sets `frame.stopped = true` |
| `0x56` | [handler_0x56_JUMP](/evm/instructions/control-flow/jump) | `8` | `dest ->` | Sets `frame.pc = dest` if valid `JUMPDEST`; else `{ type: "InvalidJump" }` |
| `0x57` | [handler_0x57_JUMPI](/evm/instructions/control-flow/jumpi) | `10` | `dest, cond ->` | Jumps to `dest` if `cond !== 0n`; else `frame.pc += 1` |
| `0x58` | [handler_0x58_PC](/evm/instructions/control-flow/pc) | `2` | `-> pc` | Pushes current `frame.pc` before incrementing |
| `0x5b` | [handler_0x5b_JUMPDEST](/evm/instructions/control-flow/jumpdest) | `1` | `->` | Valid jump target marker (no-op) |
| `0xf3` | [handler_0xf3_RETURN](/evm/instructions/control-flow/return) | `0 + mem` | `offset, size ->` | Copies `memory[offset..offset+size]` to `frame.output`, sets `stopped = true` |
| `0xfd` | [handler_0xfd_REVERT](/evm/instructions/control-flow/revert) | `0 + mem` | `offset, size ->` | Copies revert payload to `frame.output`, sets `reverted = true` (Byzantium+) |

## Usage

```typescript
import { Control, Frame } from '@tevm/voltaire/evm';

// Bytecode: [0x56 (JUMP), 0x00, 0x5b (JUMPDEST)]
const frame = Frame({
  bytecode: new Uint8Array([0x56, 0x00, 0x5b]),
  gas: 1000n,
});
Frame.pushStack(frame, 2n);

const err = Control.handler_0x56_JUMP(frame); // null
console.log(err, frame.pc); // null, 2
```
