---
title: Block Instructions
description: EVM block header and fee context opcode handlers (0x40-0x4a).
---

`Block` (`@tevm/voltaire/evm`) implements the `11` block-context opcodes (`0x40`-`0x4a`) reading block metadata from `frame` (`blockNumber`, `blockTimestamp`, `coinbase`, `blockGasLimit`, `blockPrevrandao`, `chainId`, `blockBaseFee`, `blobBaseFee`, `blockHashes`, `blobVersionedHashes`, `selfBalance`).

## Opcode Table

| Opcode | Export | Gas | Hardfork | Pushes |
|--------|--------|-----|----------|--------|
| `0x40` | [handler_0x40_BLOCKHASH](/evm/instructions/block/blockhash) | `20` | Frontier | Hash of one of the 256 most recent blocks (`0` otherwise) |
| `0x41` | [handler_0x41_COINBASE](/evm/instructions/block/coinbase) | `2` | Frontier | Block beneficiary address |
| `0x42` | [handler_0x42_TIMESTAMP](/evm/instructions/block/timestamp) | `2` | Frontier | Block Unix timestamp |
| `0x43` | [handler_0x43_NUMBER](/evm/instructions/block/number) | `2` | Frontier | Current block number |
| `0x44` | [handler_0x44_DIFFICULTY](/evm/instructions/block/difficulty) | `2` | Frontier / Paris | `PREVRANDAO` post-Merge (EIP-4399) |
| `0x45` | [handler_0x45_GASLIMIT](/evm/instructions/block/gaslimit) | `2` | Frontier | Block gas limit |
| `0x46` | [handler_0x46_CHAINID](/evm/instructions/block/chainid) | `2` | Istanbul | EIP-155 chain ID |
| `0x47` | [handler_0x47_SELFBALANCE](/evm/instructions/block/selfbalance) | `5` | Istanbul | Executing contract balance in wei |
| `0x48` | [handler_0x48_BASEFEE](/evm/instructions/block/basefee) | `2` | London | EIP-1559 block base fee |
| `0x49` | [handler_0x49_BLOBHASH](/evm/instructions/block/blobhash) | `3` | Cancun | `index`-th blob versioned hash (`0` if out of range, EIP-4844) |
| `0x4a` | [handler_0x4a_BLOBBASEFEE](/evm/instructions/block/blobbasefee) | `2` | Cancun | Current block blob base fee (EIP-7516) |

## Usage

```typescript
import { Block, Frame } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 1000n });
frame.chainId = 1n;

const err = Block.handler_0x46_CHAINID(frame); // null
console.log(err, Frame.popStack(frame).value); // null, 1n
```
