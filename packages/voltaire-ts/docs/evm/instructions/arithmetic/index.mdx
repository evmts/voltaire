title: Arithmetic Instructions
description: EVM arithmetic opcode handlers (0x01-0x0b) operating on 256-bit words modulo 2^256.
---

`Arithmetic` (`@tevm/voltaire/evm`) implements the `11` EVM integer arithmetic opcodes (`0x01`-`0x0b`). All values are 256-bit unsigned bigints; `ADD`, `MUL`, and `SUB` wrap modulo `2^256`, while `DIV`, `SDIV`, `MOD`, `SMOD`, `ADDMOD`, and `MULMOD` return `0n` when the divisor or modulus is `0n`.

## Opcode Table

| Opcode | Handler | Base Gas | Stack (`top` first) | Semantics |
|--------|---------|----------|---------------------|-----------|
| `0x01` | [add](/evm/instructions/arithmetic/add) | `3` | `a, b -> (a + b) mod 2^256` | Unsigned wrapping addition |
| `0x02` | [mul](/evm/instructions/arithmetic/mul) | `5` | `a, b -> (a * b) mod 2^256` | Unsigned wrapping multiplication |
| `0x03` | [sub](/evm/instructions/arithmetic/sub) | `3` | `a, b -> (a - b) mod 2^256` | Unsigned wrapping subtraction |
| `0x04` | [div](/evm/instructions/arithmetic/div) | `5` | `a, b -> floor(a / b)` | Unsigned integer division (`0` if `b == 0`) |
| `0x05` | [sdiv](/evm/instructions/arithmetic/sdiv) | `5` | `a, b -> trunc(a / b)` | Two's-complement signed division (`-2^255 / -1 = -2^255`) |
| `0x06` | [mod](/evm/instructions/arithmetic/mod) | `5` | `a, b -> a % b` | Unsigned remainder (`0` if `b == 0`) |
| `0x07` | [smod](/evm/instructions/arithmetic/smod) | `5` | `a, b -> a % b` | Signed remainder (sign matches dividend `a`) |
| `0x08` | [addmod](/evm/instructions/arithmetic/addmod) | `8` | `a, b, N -> (a + b) % N` | Intermediate sum does not overflow 256 bits |
| `0x09` | [mulmod](/evm/instructions/arithmetic/mulmod) | `8` | `a, b, N -> (a * b) % N` | Intermediate product does not overflow 256 bits |
| `0x0a` | [exp](/evm/instructions/arithmetic/exp) | `10 + 50/byte` | `a, exp -> a^exp mod 2^256` | Dynamic gas scales with byte length of `exp` |
| `0x0b` | [signextend](/evm/instructions/arithmetic/signextend) | `5` | `b, x -> y` | Extends sign bit of byte `b` (`0` = lowest byte) across 256 bits |

## Usage

Each handler takes `frame: BrandedFrame`, mutates `stack`, `gasRemaining`, and `pc`, and returns `EvmError | null`. The same 11 operations are also bound directly as methods on `frame` (`frame.add()`, `frame.mul()`, etc.).

```typescript
import { Arithmetic, Frame } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 1000n });
Frame.pushStack(frame, 10n);
Frame.pushStack(frame, 32n);

const err = Arithmetic.add(frame); // null on success
console.log(err, Frame.popStack(frame).value); // null, 42n
```
