title: Context Instructions
description: EVM call, calldata, code, return data, and external account opcode handlers (0x30-0x3f).
---

`Context` (`@tevm/voltaire/evm`) implements the `16` execution-context opcodes (`0x30`-`0x3f`). Opcodes that inspect external accounts (`balance`, `extcodesize`, `extcodecopy`, `extcodehash`) take `(frame, host)` and apply EIP-2929 warm/cold gas accounting.

## Opcode Table

| Opcode | Handler | Gas | Args | Description |
|--------|---------|-----|------|-------------|
| `0x30` | [address](/evm/instructions/context/address) | `2` | `(frame)` | Executing account address |
| `0x31` | [balance](/evm/instructions/context/balance) | `100 / 2600` | `(frame, host)` | Balance of target address in wei |
| `0x32` | [origin](/evm/instructions/context/origin) | `2` | `(frame)` | Transaction origin (`tx.origin`) |
| `0x33` | [caller](/evm/instructions/context/caller) | `2` | `(frame)` | Direct caller (`msg.sender`) |
| `0x34` | [callvalue](/evm/instructions/context/callvalue) | `2` | `(frame)` | Wei attached to call (`msg.value`) |
| `0x35` | [calldataload](/evm/instructions/context/calldataload) | `3` | `(frame)` | 32-byte word from calldata (right-padded with zeros) |
| `0x36` | [calldatasize](/evm/instructions/context/calldatasize) | `2` | `(frame)` | Byte length of `frame.calldata` |
| `0x37` | [calldatacopy](/evm/instructions/context/calldatacopy) | `3 + 3/word + mem` | `(frame)` | Copy calldata slice to memory |
| `0x38` | [codesize](/evm/instructions/context/codesize) | `2` | `(frame)` | Byte length of `frame.bytecode` |
| `0x39` | [codecopy](/evm/instructions/context/codecopy) | `3 + 3/word + mem` | `(frame)` | Copy bytecode slice to memory |
| `0x3a` | [gasprice](/evm/instructions/context/gasprice) | `2` | `(frame)` | Effective gas price |
| `0x3b` | [extcodesize](/evm/instructions/context/extcodesize) | `100 / 2600` | `(frame, host)` | Byte length of external account code |
| `0x3c` | [extcodecopy](/evm/instructions/context/extcodecopy) | `100 / 2600 + 3/word + mem` | `(frame, host)` | Copy external account code to memory |
| `0x3d` | [returndatasize](/evm/instructions/context/returndatasize) | `2` | `(frame)` | Length of `frame.returnData` (Byzantium+) |
| `0x3e` | [returndatacopy](/evm/instructions/context/returndatacopy) | `3 + 3/word + mem` | `(frame)` | Copy `frame.returnData` (fails on out-of-bounds) |
| `0x3f` | [extcodehash](/evm/instructions/context/extcodehash) | `100 / 2600` | `(frame, host)` | Keccak-256 of external code (`0` if empty account, Constantinople+) |

## Usage

```typescript
import { Address } from '@tevm/voltaire';
import { Context, Frame } from '@tevm/voltaire/evm';

const frame = Frame({
  caller: Address('0x1111111111111111111111111111111111111111'),
  calldata: new Uint8Array([0xa9, 0x05, 0x9c, 0xbb]),
  gas: 10_000n,
});

Context.calldatasize(frame);
console.log(Frame.popStack(frame).value); // 4n
```
