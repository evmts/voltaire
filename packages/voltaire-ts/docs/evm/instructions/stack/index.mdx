title: Stack Instructions
description: EVM stack manipulation opcode handlers (POP, PUSH0-PUSH32, DUP1-DUP16, SWAP1-SWAP16).
---

`Stack` (`@tevm/voltaire/evm`) implements all `66` stack manipulation opcodes (`0x50`, `0x5f`-`0x9f`) operating on `frame.stack` (max depth `1024` 256-bit words).

## Opcode Families

| Family | Opcodes | Count | Gas | Export Pattern | Behavior |
|--------|---------|-------|-----|----------------|----------|
| `POP` | `0x50` | 1 | `2` | `handler_0x50_POP` | Discards top word |
| `PUSH0` | `0x5f` | 1 | `2` | `handler_0x5f_PUSH0` | Pushes `0n` (EIP-3855, Shanghai+) |
| `PUSH1`-`PUSH32` | `0x60`-`0x7f` | 32 | `3` | `handler_0x60_PUSH1` .. `handler_0x7F_PUSH32` | Reads `N` immediate bytes after `pc` (zero-padded at end of bytecode), advances `pc` by `1 + N` |
| `DUP1`-`DUP16` | `0x80`-`0x8f` | 16 | `3` | `handler_0x80_DUP1` .. `handler_0x8F_DUP16` | Duplicates `N`-th item from top onto top of stack |
| `SWAP1`-`SWAP16` | `0x90`-`0x9f` | 16 | `3` | `handler_0x90_SWAP1` .. `handler_0x9F_SWAP16` | Swaps top item with `(N + 1)`-th item |

## Usage

```typescript
import { Frame, Stack } from '@tevm/voltaire/evm';

const frame = Frame({
  bytecode: new Uint8Array([0x60, 0x2a, 0x80, 0x50]), // PUSH1 0x2a, DUP1, POP
  gas: 1000n,
});

Stack.handler_0x60_PUSH1(frame); // stack: [42n], pc: 2
Stack.handler_0x80_DUP1(frame);  // stack: [42n, 42n], pc: 3
Stack.handler_0x50_POP(frame);   // stack: [42n], pc: 4
```
