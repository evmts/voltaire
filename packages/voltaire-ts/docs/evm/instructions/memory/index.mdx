`Memory` (`@tevm/voltaire/evm`) implements the `4` byte-addressable volatile memory opcodes (`0x51`-`0x53`, `0x5e`). Memory starts empty, reads `0` at unwritten offsets, expands in 32-byte words with quadratic gas cost `3 * words + floor(words^2 / 512)`, and is discarded when the call frame exits.

## Opcode Table

| Opcode | Handler | Gas | Stack (`top` first) | Hardfork |
|--------|---------|-----|---------------------|----------|
| `0x51` | [mload](/evm/instructions/memory/mload) | `3 + mem` | `offset -> value` | Frontier |
| `0x52` | [mstore](/evm/instructions/memory/mstore) | `3 + mem` | `offset, value ->` | Frontier |
| `0x53` | [mstore8](/evm/instructions/memory/mstore8) | `3 + mem` | `offset, value ->` | Frontier |
| `0x5e` | [mcopy](/evm/instructions/memory/mcopy) | `3 + 3 * words + mem` | `destOffset, srcOffset, size ->` | Cancun (EIP-5656) |

## Usage

```typescript
import { Frame, Memory } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 10_000n });

// MSTORE(offset = 0, value = 0x1234)
Frame.pushStack(frame, 0x1234n); // value
Frame.pushStack(frame, 0n);      // offset (top)
Memory.mstore(frame);

// MLOAD(offset = 0)
Frame.pushStack(frame, 0n);
Memory.mload(frame);
console.log(Frame.popStack(frame).value); // 0x1234n
```

`mcopy` handles overlapping source and destination ranges safely (equivalent to `memmove`).
