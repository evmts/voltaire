---
title: Bitwise Instructions
description: EVM bitwise logic, byte extraction, and shift opcode handlers (0x16-0x1d).
---

`Bitwise` (`@tevm/voltaire/evm`) implements the `8` EVM bit-manipulation opcodes (`0x16`-`0x1d`), each costing `3` gas.

## Opcode Table

| Opcode | Handler | Gas | Stack (`top` first) | Semantics |
|--------|---------|-----|---------------------|-----------|
| `0x16` | [AND](/evm/instructions/bitwise/and) | `3` | `a, b -> a & b` | 256-bit bitwise AND |
| `0x17` | [OR](/evm/instructions/bitwise/or) | `3` | `a, b -> a \| b` | 256-bit bitwise OR |
| `0x18` | [XOR](/evm/instructions/bitwise/xor) | `3` | `a, b -> a ^ b` | 256-bit bitwise XOR |
| `0x19` | [NOT](/evm/instructions/bitwise/not) | `3` | `a -> ~a mod 2^256` | 256-bit bitwise NOT |
| `0x1a` | [BYTE](/evm/instructions/bitwise/byte) | `3` | `i, x -> (x >> (248 - i*8)) & 0xff` | Big-endian byte `i` (`0` if `i >= 32`) |
| `0x1b` | [SHL](/evm/instructions/bitwise/shl) | `3` | `shift, val -> (val << shift) mod 2^256` | Shift left (`0` if `shift >= 256`, Constantinople+) |
| `0x1c` | [SHR](/evm/instructions/bitwise/shr) | `3` | `shift, val -> val >> shift` | Logical shift right (`0` if `shift >= 256`, Constantinople+) |
| `0x1d` | [SAR](/evm/instructions/bitwise/sar) | `3` | `shift, val -> val >> shift` | Arithmetic (sign-extending) shift right (Constantinople+) |

## Usage

```typescript
import { Bitwise, Frame } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 1000n });
Frame.pushStack(frame, 0xffn);
Frame.pushStack(frame, 4n); // top of stack = shift

const err = Bitwise.SHL(frame); // null
console.log(err, Frame.popStack(frame).value); // null, 0xff0n
```
