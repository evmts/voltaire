---
title: Comparison Instructions
description: EVM unsigned/signed comparison and zero-check opcode handlers (0x10-0x15).
---

`Comparison` (`@tevm/voltaire/evm`) implements the `6` comparison opcodes (`0x10`-`0x15`) plus the `toSigned256` helper. Every opcode costs `3` gas and pushes `1n` (true) or `0n` (false).

## Opcode Table

| Opcode | Handler | Gas | Stack (`top` first) | Semantics |
|--------|---------|-----|---------------------|-----------|
| `0x10` | [LT](/evm/instructions/comparison/lt) | `3` | `a, b -> a < b ? 1 : 0` | Unsigned less-than |
| `0x11` | [GT](/evm/instructions/comparison/gt) | `3` | `a, b -> a > b ? 1 : 0` | Unsigned greater-than |
| `0x12` | [SLT](/evm/instructions/comparison/slt) | `3` | `a, b -> signed(a) < signed(b)` | Two's-complement signed less-than |
| `0x13` | [SGT](/evm/instructions/comparison/sgt) | `3` | `a, b -> signed(a) > signed(b)` | Two's-complement signed greater-than |
| `0x14` | [EQ](/evm/instructions/comparison/eq) | `3` | `a, b -> a == b ? 1 : 0` | Equality |
| `0x15` | [ISZERO](/evm/instructions/comparison/iszero) | `3` | `a -> a == 0 ? 1 : 0` | Logical NOT / zero test |

## Usage

```typescript
import { Comparison, Frame } from '@tevm/voltaire/evm';

const frame = Frame({ gas: 1000n });
Frame.pushStack(frame, 10n);
Frame.pushStack(frame, 5n); // top of stack = a = 5, second = b = 10

const err = Comparison.LT(frame); // 5 < 10 -> 1n
console.log(err, Frame.popStack(frame).value); // null, 1n
```
