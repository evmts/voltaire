`System` (`@tevm/voltaire/evm`) implements the `7` system opcodes (`0xf0`-`0xf2`, `0xf4`-`0xf5`, `0xfa`, `0xff`). All handlers take `(frame, host)` and delegate nested frame execution to `host.call` or `host.create`.

## Call Context Matrix

| Opcode | Handler | `msg.sender` | `msg.value` | Storage Context | State Writes | Hardfork |
|--------|---------|--------------|-------------|-----------------|--------------|----------|
| `0xf0` | [create](/evm/instructions/system/create) | current contract | `value` | new contract | Allowed | Frontier |
| `0xf5` | [create2](/evm/instructions/system/create2) | current contract | `value` | new contract | Allowed | Constantinople |
| `0xf1` | [call](/evm/instructions/system/call) | current contract | `value` | callee | Allowed (`value == 0` in static) | Frontier |
| `0xf2` | [callcode](/evm/instructions/system/callcode) | current contract | `value` | caller | Allowed (deprecated) | Frontier |
| `0xf4` | [delegatecall](/evm/instructions/system/delegatecall) | preserved | preserved | caller | Inherits `isStatic` | Homestead |
| `0xfa` | [staticcall](/evm/instructions/system/staticcall) | current contract | `0` | callee | Forbidden (`isStatic = true`) | Byzantium |
| `0xff` | [selfdestruct](/evm/instructions/system/selfdestruct) | — | transfers balance | current contract | Allowed (EIP-6780 Cancun+) | Frontier |

## Gas Forwarding (EIP-150)

Nested calls and contract creations forward at most `63/64` of remaining gas:

```text
maxForwarded = gasRemaining - floor(gasRemaining / 64)
```

Non-zero value transfers on `CALL` add a `9,000`-gas transfer charge (plus `25,000` if creating a new empty account) and grant the callee a `2,300`-gas stipend.

<Note>
If `host.call` or `host.create` is not implemented on the supplied `BrandedHost`, these handlers return `{ type: "NotImplemented", message: ... }`. Provide a full execution host (such as [guillotine](https://github.com/evmts/guillotine)) to execute nested frames.
</Note>
