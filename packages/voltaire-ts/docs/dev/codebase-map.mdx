This map reflects the actual monorepo structure across `packages/`, `wasm/`, `zig-out/`, and root tooling configs.

## Top-Level Layout

```text
voltaire/
├── packages/
│   ├── voltaire-ts/         # @tevm/voltaire SDK + Mintlify docs
│   ├── voltaire-zig/        # Core Zig modules, C ABI, vendored C libs
│   ├── voltaire-effect/     # Effect 4 transports, errors, services (.vibe)
│   ├── voltaire-rs/         # Rust bindings crate
│   ├── voltaire-go/         # Go CGo bindings
│   ├── voltaire-py/         # Python bindings
│   ├── voltaire-swift/      # Swift Package Manager bindings (macOS/iOS)
│   └── voltaire-c/          # Direct C headers and examples
├── wasm/                    # Built .wasm binaries (primitives, state-manager, blockchain, crypto/)
├── zig-out/                 # Zig build outputs (lib/, native/, wasm/)
├── scripts/                 # Benchmarks, bundle size, codegen scripts
├── tests/                   # Cross-package integration tests
├── build.zig                # Master Zig build graph (native, WASM, C libs, tests)
├── build.zig.zon            # Zig package dependencies
├── Cargo.toml               # Rust workspace (crypto_wrappers + voltaire-rs)
├── pnpm-workspace.yaml      # pnpm workspace definition
├── package.json             # Root workspace scripts
└── biome.json               # Formatter and linter config
```

## `packages/voltaire-ts/` (`@tevm/voltaire`)

```text
packages/voltaire-ts/
├── src/
│   ├── primitives/          # Branded Ethereum types (Address, Abi, Hash, Hex, Rlp, Transaction, Uint, ...)
│   ├── crypto/              # Keccak256, Secp256k1, Bls12381, BN254, KZG, EIP712, HDWallet, Keystore, ...
│   ├── provider/            # HttpProvider, WebSocketProvider, InMemoryProvider, ForkProvider, EIP6963, RpcSchema
│   ├── jsonrpc/             # OpenRPC request builders (eth, wallet, debug, engine, anvil, hardhat, web3, net, txpool)
│   ├── contract/            # EventStream (backfill + watch with adaptive chunking)
│   ├── block/               # BlockStream (reorg-aware block streaming)
│   ├── stream/              # Shared stream errors (StreamAbortedError)
│   ├── standards/           # ERC20, ERC721, ERC1155, ERC165 helpers
│   ├── utils/               # retryWithBackoff, RateLimiter, poll*, withTimeout, BatchQueue, AsyncQueue
│   ├── evm/                 # Frame, Host, instructions, precompiles
│   ├── state-manager/       # FFI / WASM StateManager bridge
│   ├── blockchain/          # FFI / WASM Blockchain bridge
│   ├── wasm/                # @tevm/voltaire/wasm entrypoint
│   ├── wasm-loader/         # Linear memory loader & WASM bindings
│   ├── native/              # @tevm/voltaire/native Bun FFI entrypoint
│   ├── index.ts             # Default @tevm/voltaire entrypoint
│   └── functional.ts        # @tevm/voltaire/functional entrypoint
├── docs/                    # Mintlify v4 documentation site
├── dist/                    # Compiled ESM (.js) and CJS (.cjs) outputs (tsup)
├── types/                   # Emitted TypeScript declaration files (.d.ts)
├── package.json             # Subpath exports map & package scripts
└── tsup.config.ts           # Bundler entrypoints
```

## `packages/voltaire-zig/`

```text
packages/voltaire-zig/
├── src/
│   ├── primitives/          # Address, Hash, Hex, Rlp, Abi, Transaction, Block, Hardfork, ...
│   ├── crypto/              # Keccak256, Secp256k1, BN254, Bls12381, KZG, EIP712, ...

│   ├── evm/                 # EVM execution primitives
│   ├── state-manager/       # In-memory & forked state manager
│   ├── blockchain/          # Block storage & fork backend
│   ├── jsonrpc/             # Zig JSON-RPC types
│   ├── c_api.zig            # C ABI exports (FFI / WASM / Swift / Go / Python / C)
│   ├── primitives.h         # Generated C header (`zig build generate-header`)
│   └── root.zig             # Package root
└── lib/
    ├── c_libs.zig           # Build helpers for blst, c-kzg-4844, Rust crypto_wrappers
    ├── blst/                # Vendored BLS12-381 C library
    ├── c-kzg-4844/          # Vendored EIP-4844 KZG C library
    └── libwally-core/       # Optional C wallet utilities (enabled with -Dwith-c-api=true)
```

## Build Output Directories

| Output Directory | Produced By | Contents |
| --- | --- | --- |
| `zig-out/lib/` | `zig build` | `libblst.a`, `libc_kzg.a`, `libcrypto_wrappers.a` |
| `zig-out/native/` | `zig build build-ts-native -Dwith-c-api=true` | `libprimitives_ts_native.{dylib,so,dll}` |
| `wasm/` | `zig build build-ts-wasm`, `build-ts-wasm-fast` | `primitives.wasm`, `primitives-fast.wasm`, `state-manager.wasm`, `blockchain.wasm`, `crypto/*.wasm` |
| `packages/voltaire-ts/dist/` | `pnpm --filter @tevm/voltaire build:dist` | ESM (`.js`) and CJS (`.cjs`) bundles |
| `packages/voltaire-ts/types/` | `pnpm --filter @tevm/voltaire build:types` | `.d.ts` declaration trees |

## File Naming Conventions

| Pattern | Meaning | Example |
| --- | --- | --- |
| `*Type.ts` | Branded TypeScript type definition | `AddressType.ts` |
| `*.js` | Tree-shakeable JS implementation with JSDoc types | `EventStream.js`, `Abi.js` |
| `*.ts` | TypeScript module or re-export barrel | `HttpProvider.ts`, `index.ts` |
| `*.test.ts` / `*.test-d.ts` | Vitest runtime tests / type-level tests | `EventStream.test.ts`, `EventStream.test-d.ts` |
| `*.wasm.ts` / `*.native.ts` | WASM or Bun FFI implementation variant | `Keccak256.wasm.ts`, `Keccak256.native.ts` |
| `*.zig` | Zig implementation with inline `test` blocks | `c_api.zig` |
| `*.vibe` | VibeLang source compiled by `voltaire-effect` | `FallbackTransport.vibe` |
