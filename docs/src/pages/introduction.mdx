# Introduction

Voltaire is an Ethereum **primitives and cryptography** toolchain. It is not a
node, not an EVM, and not an RPC client framework — it is the layer underneath
all of those: the types and algorithms that define what an Ethereum address, a
transaction, an ABI-encoded call, or a signature *is*.

The core is written in Zig. Everything else is a binding.

## What is in the box

**Primitives** (`packages/voltaire-zig/src/primitives`, mirrored in TypeScript at
`packages/voltaire-ts/src/primitives`):

`Abi`, `AccessList`, `Address`, `Authorization` (EIP-7702), `Base64`,
`BinaryTree`, `Blob` (EIP-4844), `BloomFilter`, `Bytecode`, `Bytes`, `Chain`,
`ContractCode`, `Denomination`, `Ens`, `EventLog`, `FeeMarket`, `GasConstants`,
`Hardfork`, `Hash`, `Hex`, `InitCode`, `LogFilter`, `Opcode`, `PrivateKey`,
`PublicKey`, `Rlp`, `Signature`, `Siwe`, `State`, `Transaction`, `Trie`, `Uint`.

**Cryptography** (`crypto/`):

`AesGcm`, `Bip39`, `Blake2`, `Bls12381`, `BN254`, `ChaCha20Poly1305`, `Ed25519`,
`EIP712`, `HDWallet`, `HMAC`, `Keccak256`, `Keystore`, `KZG`, `ModExp`, `P256`,
`Ripemd160`, `Secp256k1`, `SHA256`, `X25519`, plus signer abstractions.

**EVM support**: the ten-plus precompiles (`0x01`–`0x0a` and the BLS set), gas
constants, opcode metadata, a state manager, and a blockchain module — the
pieces an execution client needs but that are not themselves an interpreter.

## Why it exists

Three reasons, in order of how much they cost the ecosystem.

**1. Everyone reimplements this layer, and the reimplementations disagree.**
A wallet, an indexer, a compiler, and an EVM all need RLP and ABI codecs. Each
tends to grow its own. The disagreements never show up in the happy path; they
show up in static tuple head sizes, in non-canonical RLP length prefixes, in
whether a signature with high `s` is accepted, in EIP-55 checksums applied to
already-checksummed input. Those are the exact places value goes missing.
Voltaire is one implementation, cross-validated against `@noble/curves`,
`@noble/hashes`, `ox`, `viem`, and `ethers` in its own test suite.

**2. Language silos.** A Python indexer, a Go relayer, and a Zig EVM should not
each carry a different notion of "address". Voltaire compiles to a static or
shared library with a stable C ABI (`packages/voltaire-ts/src/primitives.h`,
generated by `zig build generate-header`) and to WebAssembly, so every binding
sits on the same bytes.

**3. Performance without giving up portability.** Zig plus assembly-optimized
Keccak and arkworks-backed pairings for native builds; a WebAssembly build for
browsers; and a pure-JavaScript fallback so `npm install` never requires a
compiler. See [Native, WASM & Portable JS](/native/backends).

## Design principles

**Data-first, tree-shakeable TypeScript.** There are no fat classes. Values are
branded `Uint8Array`s or `bigint`s, and operations are free functions grouped in
namespaces:

```ts
import * as Address from '@tevm/voltaire/Address'

const a = Address.from('0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045')
Address.toChecksummed(a)
```

Importing `@tevm/voltaire/Address` pulls in the address module and nothing else —
every primitive has its own package export path.

**Branded types.** `Address` is a `Uint8Array` with a phantom tag, so a raw
20-byte buffer will not type-check where an address is required. The brand is
erased at runtime; there is no wrapper object and no allocation.

**Constant-time where it matters.** Comparisons on secret material accumulate
differences instead of returning early:

```zig
var result: u8 = 0;
for (a, b) |x, y| result |= x ^ y;
```

Signature and scalar arithmetic on secp256k1 follows the same rule.

**No hidden logging.** Library code never writes to stdout or stderr; failures
throw typed errors (`packages/voltaire-ts/src/primitives/errors`) so the calling
application owns its own observability.

## Which entry point should I use?

| You are building                                  | Use                                            |
| ------------------------------------------------- | ---------------------------------------------- |
| A TypeScript app or library                        | `@tevm/voltaire`                               |
| A TypeScript app with typed errors + DI            | [`voltaire-effect`](/guides/effect)            |
| A browser bundle that wants WASM speed             | `@tevm/voltaire/wasm`                          |
| A Bun/Node server that can load a native `.dylib`  | `@tevm/voltaire/native`                        |
| A Zig program                                      | [`zig fetch --save`](/native/zig)              |
| Rust, Python, Go, Swift, or C                       | [Other Languages](/native/other-languages)     |
