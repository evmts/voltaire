# Reference — Primitives

Member lists below were read off the built package, not written from memory. They
are the useful subset, not exhaustive — `Object.keys(await import('@tevm/voltaire/<Name>'))`
is always the complete answer.

:::tip
Import style matters for some modules. `@tevm/voltaire/Address` re-exports the
sub-namespaces; the flat function set (`toChecksummed`, `isValid`, …) comes from
the barrel: `import { Address } from '@tevm/voltaire'`. When a name seems missing,
try the other import.
:::

## Core values

### `Address`
20-byte account identifier.

`from`, `fromHex`, `fromBytes`, `fromNumber`, `fromPublicKey`, `fromPrivateKey`,
`fromBase64`, `fromAbiEncoded`, `toHex`, `toBytes`, `toChecksummed`,
`toLowercase`, `toUppercase`, `toShortHex`, `toU256`, `toAbiEncoded`, `isZero`,
`equals`, `isValid`, `isValidChecksum`, `zero`, `compare`, `lessThan`,
`greaterThan`, `sortAddresses`, `deduplicateAddresses`, `clone`,
`calculateCreateAddress`, `calculateCreate2Address`, `SIZE`, `assert`,
`IsContract`. → [guide](/guides/addresses)

### `Hex`
Hex strings with validated length.

`from`, `fromBytes`, `fromNumber`, `fromBigInt`, `fromString`, `fromBoolean`,
`toBytes`, `toNumber`, `toBigInt`, `toString`, `toBoolean`, `isHex`, `validate`,
`concat`, `random`, `zero`, `size`, `isSized`, `assertSize`, `slice`, `pad`,
`padRight`, `trim`, `equals`, `xor`, `clone`.

### `Bytes`
Raw byte arrays with the operations you keep rewriting.

`from`, `fromHex`, `fromBigInt`, `fromNumber`, `fromString`, `zero`, `random`,
`clone`, `compare`, `concat`, `equals`, `isBytes`, `isEmpty`, `padLeft`,
`padRight`, `size`, `slice`, `trimLeft`, `trimRight`, `toBigInt`, `toHex`,
`toNumber`, `toString`, `assert`.

### `Hash`
32-byte digests.

`from`, `fromBytes`, `fromHex`, `keccak256`, `keccak256String`, `keccak256Hex`,
`random`, `toBytes`, `toHex`, `equals`, `isZero`, `isHash`, `isValidHex`,
`clone`, `slice`, `concat`, `format`, `merkleRoot`, `assert`, `ZERO`, `SIZE`.

### `Uint`
`uint256`, wrapping mod 2²⁵⁶, branded over `bigint`.

`from`, `tryFrom`, `fromHex`, `fromBigInt`, `fromNumber`, `fromBytes`,
`fromAbiEncoded`, `toHex`, `toBigInt`, `toNumber`, `toBytes`, `toAbiEncoded`,
`plus`, `minus`, `times`, `dividedBy`, `modulo`, `toPower`, `gcd`, `bitwiseAnd`,
`bitwiseOr`, `bitwiseXor`, `bitwiseNot`, `shiftLeft`, `shiftRight`, `equals`,
`lessThan`, `greaterThan`, `greaterThanOrEqual`, `isZero`, `isPowerOf2`,
`minimum`, `maximum`, `bitLength`, `leadingZeros`, `popCount`, `isValid`,
`MAX`, `MIN`, `ZERO`, `ONE`, `SIZE`. → [guide](/guides/units)

### `Denomination`
`Wei`, `Gwei`, `Ether` namespaces plus their branded types. Each has `from` and
`to*`/`from*` converters and `toU256`. → [guide](/guides/units)

### `Base64`
`encode`, `decode`, `encodeString`, `decodeToString`, `encodeUrlSafe`,
`decodeUrlSafe`, `encodeStringUrlSafe`, `decodeUrlSafeToString`, `from`,
`fromUrlSafe`, `toBase64`, `toBase64Url`, `toBytes`, `toBytesUrlSafe`,
`isValid`, `isValidUrlSafe`, `calcEncodedSize`, `calcDecodedSize`.

## Keys and signatures

### `PrivateKey`
`from` (hex → 32 validated bytes), `fromBytes`, `toHex`, `toPublicKey`,
`toAddress`, `sign`. Range-checked against the curve order.

### `PublicKey`
`from`, `fromPrivateKey`, `compress`, `decompress`, `isCompressed`, `toAddress`,
`toHex`, `verify`.

### `Signature`
`from`, `fromBytes`, `fromHex`, `fromCompact`, `fromDER`, `fromTuple`,
`fromRpc`, `fromSecp256k1`, `fromEd25519`, `fromP256`, `getR`, `getS`, `getV`,
`getAlgorithm`, `isCanonical`, `equals`, `is`, plus `COMPONENT_SIZE`,
`ECDSA_SIZE`, `ECDSA_WITH_V_SIZE`, `ED25519_SIZE`, `RECOVERY_ID_MIN/MAX` and
typed errors including `NonCanonicalSignatureError`.
→ [guide](/guides/keys-and-signatures)
