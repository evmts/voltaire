# Reference — Overview

Every module below is a real entry in `packages/voltaire-ts/package.json`'s
`exports` map, so `@tevm/voltaire/<Name>` resolves for each one.

## How to read the API

**Namespaces, not classes.** Each module is a namespace of free functions taking
data as the first argument:

```js
import * as Address from '@tevm/voltaire/Address'
Address.toChecksummed(address)
```

**Naming.** `Type.fromFoo` constructs from `Foo`; `Type.toFoo` converts to `Foo`;
`Type.from` is the general constructor; `Type.is*` / `Type.isValid*` are
predicates; `Type.assert*` throws instead of returning a boolean.

**Two layers.** Many modules export both a public wrapper and an internal
`_`-prefixed variant:

```js
Address.toHex('0x…') // wrapper: accepts loose input, converts for you
Address._toHex(addr) // internal: requires an already-branded Address, no conversion
```

Use the wrapper unless you are in a hot loop with values you already validated.

**Errors, not sentinels.** Failures throw typed errors from
`@tevm/voltaire/errors`, each carrying a `_tag`, a `code`, a `docsPath`, and
context. Nothing returns `null` to mean "invalid".

## Known API rough edges

Documented here because they change how you call the library today, not as
aspiration:

- **`Abi` whole-ABI functions are `this`-bound.** `Abi.encode(abi, name, args)`
  throws `this.find is not a function`; use `Abi.encode.call(abi, name, args)`, or
  prefer the item-level `Abi.Function.*` / `Abi.Event.*` API.
  See [ABI Encoding](/guides/abi).
- **`Transaction` namespaces are inconsistent.** `EIP1559.*` takes the transaction
  as an argument; `Legacy.*` requires `.call(tx)`.
  See [Transactions](/guides/transactions).
- **Some modules are absent from the barrel.** `PrivateKey`, `PublicKey`,
  `Denomination`, `HDWallet`, `Keystore`, `KZG`, and `Transaction`'s per-type
  namespaces must be imported from their subpath.
- **`Siwe.format` emits a lowercase address**, where EIP-4361 requires EIP-55.
  See [EIP-712 Typed Data](/guides/eip712).
- **KZG is unavailable from the portable JS entry point.** Use WASM (with the
  module loaded) or native.

## Generating a fuller API reference

The TypeScript package is configured for TypeDoc (`typedoc.json`, with the
markdown and frontmatter plugins). The source is the authority — every function
carries JSDoc with `@param`, `@returns`, `@throws`, `@example`, and a `@see` link.
